"HI-LO for B8Script. Guess a secret number from 0 to 127 in 7 tries.";
"Keys: any key to start; then type a number and press Return, for each guess.";
"Each guess is answered with < (too low), > (too high) or = (right). Lose, and the";
"  number is shown. 7 tries always suffice with a binary search, as 2^7 = 128.";
"Variables: s the secret number, g the last guess. The tries left live on the stack.";

"N ( -- n ): read a number from the keys. The total starts at 0 and the loop reads a";
"  key with 0? (it waits, and does not echo). Return (13) ends the loop, with the";
"  total and the key left on the stack, and the ; after the loop drops the key. Any";
"  other key is echoed, has 48 taken off (so a digit key gives its value), and is";
"  added to the total times 10. Return itself is not echoed, so the reply lands on";
"  the same line as the guess.";
[N 0 1(
     0? :13= \
     : ' 48- % 10* + 1)
   ;]

"Start: print the rules, then count up (masked with 127) while polling for a key.";
"  The key's timing makes the count, which is s: a number from 0 to 127. The key";
"  itself is used up by 0=, which makes the flag that repeats the loop.";
"0-127, 7 tries. Key"$
0 1( 1+ 127& 1? 0= ) s!

"Main loop: one guess per pass, with the tries left (7) on the stack under the flag.";
"  Each pass: a new line, read the guess with N and keep it in g. Then take s from";
"  it: the difference d. :0<%0>- is the sign of d: -1, 0 or +1 with no branch, and";
"  adding 61 gives the code of <, = or >, which is printed. Then 1- takes one try off.";
"  The loop goes on while tries are left (:0>) and the guess is wrong (g-s, not 0);";
"  & of the flag and the difference is nonzero only when both hold.";
7 1( 13'10'
     N :g! s@-
     :0< % 0> - 61+ '
     1-
     :0> g@ s@- &)
;

"The end. The difference is 0 for a win. If it is not 0, say what s was (//s prints s)";
"  and push 0 to leave the block. Then 0= turns the difference into the win flag.";
g@ s@- :( " was /s"$ 0)
0=( " WIN"$ 0)
