The B8Script web player

  

    
Pick a program, then press Run. Everything it prints shows on the screen, and what you type goes to it.

    
Keys

    
    
      
  • Ctrl-C, or Stop or Break, stops a program. The program never sees Ctrl-C.
    • 
      
  • The arrow keys send Esc [ and a letter (A up, B down, C right, D left), as on an ANSI terminal.
    • 
      
  • Pasting types the text, so a BASIC program can be pasted into Tiny BASIC.
    • 
    

    
On a phone

    
    
      
  • Tap the screen, or ⌨, for the phone's keyboard.
    • 
      
  • Each program has its own big keys, the ones it uses, laid out as it uses them (w a s d as a cross, Tic-tac-toe's 1 to 9 as its board). Pad shows or hides them. Movement keys repeat while held.
    • 
      
  • Ctrl, then a key, sends that control key. Ctrl and B is Tiny BASIC's break key.
    • 
      
  • Upright, while the phone's keyboard is up, everything but the screen makes way for it (for Tiny BASIC, MON and other typing), and comes back when the keyboard closes. Ctrl and Break are among what makes way: close the keyboard to use them.
    • 
      
  • Turned sideways, the screen takes the whole height, with the program's keys either side; ☰ shows the bars above and below.
    • 
    

    
Checked

    
With Checked on, the program runs as a checked build: variables start at 0, and an error (a stack underflow, an unclosed bracket, a word not defined, …) stops it with a report: Err, the error's letter, and its line and column.

    
Edit and Open

    
Edit shows the program's text: change it and press Run. Save downloads it as a file. Open runs a .B8S or .TXT from your device; you can also drop a file on the screen.

    
This build

    
    
      
  • It runs B8Script in JavaScript, following the reference interpreter step for step.
    • 
      
  • There is no CPU here, so machine code can't run: a grave that would execute code stops the program. The hex loader still stores bytes, and writes the RET byte C9h.
    • 
      
  • Memory: the letter cells at 0100h, the line buffer at 0200h, the program at 0400h, then the heap, up to FF00h.
    • 
      
  • The speed menu sets the serial line to the terminal, as on most B8Script machines: 9600 or 115200 baud, or full speed, with no line at all. A byte takes 10 bits (start, 8 data, stop), and while the line is busy the program waits, as it would for a real UART. It takes effect at once, even in a running program.
    • 
      
  • 8-bit CPU runs B8Script at the pace of a real 8-bit machine: about 24,600 steps a second, as a Z80 at 7.3728 MHz (an RC2014) does. Off, it runs as fast as the browser can. It too takes effect at once.
    • 
      
  • n? waits n milliseconds by the clock.
    • 
      
  • The screen is 80 × 24 and understands the ANSI sequences the console escapes send.
