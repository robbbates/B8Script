"LANDER for B8Script. Land a craft on the ground at a speed below 5.";
"Keys: each turn press 0 to 9, the fuel to burn this turn (space counts as 0).";
"Gravity adds 3 to the downward speed each turn and a burn takes its amount off.";
"You start at height 1000 with 99 fuel. The least fuel that lands is 89, so burn late";
"  and hard: a suicide burn.";
"Variables: h height, v downward speed, f fuel left.";
"There are no words. The whole game is one loop.";

"Title, then the start values.";
"LANDER burn 0-9, v<5"$
1000h! 0v! 99f!

"Main loop: one turn per pass, and it goes on while the height h is above 0.";
"  First a new line and the status. The string holds //h //v //f, which print the";
"  variables, so no # is needed. Then the burn: 0? waits for a key, : ' echoes it,";
"  and 15& maps the digit keys to 0-9 (and space to 0). :f@>( ; f@ 0) caps the burn";
"  at the fuel left: if burn > f, drop it and use f. Take the burn off the fuel (f).";
"  The speed is v - burn + 3. The height h is then h - v, and :h! keeps a copy as";
"  the flag, which is true while h is above 0.";
1( "/M/Jh/h v/v f/f ?"$
   0? :' 15&
   :f@> ( ; f@ 0)
   :f@ % - f!
   v@ % - 3+ v!
   h@ v@ - :h! 0>)

"The end. Print the speed. Then push one message, CRASH, and if v is below 5 replace it";
"  with LANDED (drop CRASH, push LANDED, 0 leaves the block), and print what is left.";
" v/v"$
" CRASH" v@5< ( ; " LANDED" 0) $
