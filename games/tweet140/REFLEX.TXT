"REFLEX for B8Script. Five rounds of reaction time.";
"Keys: any key to start. After wait.. and a random pause, GO! appears and you press a";
"  key as fast as you can. Its time is shown. A key during the pause scores 999.";
"Lowest total wins. Times are in polls of 1? (about a millisecond each).";
"Variables: t the last time, which also sets the next pause, s the total.";
"The rounds left live on the stack.";

"W ( -- n ): wait for a key and count the polls of 1? meanwhile. The key is used up";
"  by 0=, so n is the time. 0 is the count, and the loop adds 1 to it every pass.";
[W 0 1( 1+ 1? 0= )]

"Start: print the title, then W waits for the first key, whose time becomes t, the";
"  seed of the first pause. The total s starts at 0.";
"REFLEX: hit key at GO. Key"$
W t! 0s!

"Main loop: one round per pass, with the rounds left on the stack (5 to start).";
"  Print the new line and wait... Then wait for a key for up to (t and 2047) + 999";
"  ms with ?. It returns 0 if none came. This is an if-else, with the flag kept";
"  on the return stack by : { and brought back by } :";
"  - a key came (early): print early, and the round's value is 999;";
"  - no key came: print GO!, then W waits for a key and its time is printed and kept.";
"  The value becomes t, is added to s, and the round count goes down. It repeats";
"  while rounds are left.";
5 1( "/M/Jwait.."$
     t@2047& 999+ ?
     :{ ( " early"$ 999 0)
     } 0= ( " GO! "$ W :# 0)
     :t! s@+ s!
     1- : )
;

"The end: print the total (//s prints s).";
" total /s"$
