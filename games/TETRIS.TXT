"TETRIS for B8Script. a d move, w rotate, s down, space drops, q quits.";
"Real time: each frame waits up to 20 ms for a key (20?), so a frame lasts about 20 ms on";
"every machine, and gravity counts frames: s = 48 at level 0, so a row every 49 frames (about";
"1 s), and 4 fewer a level.";
"";
"The idea in short. The well is a grid of bytes in memory. The falling piece is NOT stored in";
"the well: it is kept as four numbers (which piece p, which turn o, and the column x and row y";
"of its 4 x 4 box). To draw it, to test it or to lock it, the program looks up the piece's";
"16-bit mask (a bit per cell of the box) and visits the cells whose bit is set. A move is";
"always done as try first, then commit: the new place is put in e f g, tested, and copied";
"to x y o only if nothing is in the way.";
"";

"Hide the cursor while it runs (/` in a string hides it): delete the next line";
"for a terminal that can't hide its cursor.";
"/`"$

"Variables";
"  w  the well: 12 x 21 bytes (0 empty, 1 block, 2 wall)";
"  t  28 shapes: 7 pieces x 4 turns, each a 16-bit mask of a 4 x 4 box";
"  p o x y  piece, turn, column, row     e f g  a position to try";
"  n  frame counter   s  frames per row   l  lines   b  level (every 10 lines)";
"  d  game over   c  key";
"  m v k z  used by the shape loops   i j u  scratch   a  string to draw";
"";
"The well. Cell (column, row) is the byte at w + row x 12 + column. Columns 0 and 11 are";
"walls (2) and row 20 is the floor (2), so the playing field is columns 1 to 10 and rows 0 to";
"19, ten wide and twenty high. Since walls and floor are not empty, a piece can never leave";
"the field and no edge tests are needed: a piece simply fits where it hits only 0 bytes.";
"A locked block is 1.";
"";
"The shapes. Shape number p x 4 + o (piece p = 0 to 6, turn o = 0 to 3) is the cell at";
"t + 2 x number: a 16-bit mask. Bit k of the mask (k = 0 to 15) is the cell in row k div 4,";
"column k mod 4 of a 4 x 4 box whose top left corner is the piece position x y. Pieces:";
"0 I, 1 O (square), 2 T, 3 S, 4 Z, 5 J, 6 L. For example 240 is bits 4 to 7, the second row";
"of the box: a horizontal bar. 17476 is bits 2 6 10 14, the third column: a vertical bar.";
"The I, S and Z pieces have only two different looks, so their turns 2 and 3 repeat 0 and 1;";
"the square repeats all four. A turn is o + 1, kept to 0 to 3 with AND 3.";
"";
"The screen. A well cell is 2 characters wide, so the well is 24 characters across and sits";
"at the top left. Screen rows and columns count from 0, so cell (column, row) is drawn at";
"screen row = row, screen column = 2 x column. The empty cell shows as space and dot, a";
"block as [], a wall as ##. The status text is to the right, from screen column 29.";
"";

"Routines";

"M: n d -- n mod d (the division leaves quotient and remainder, the quotient is dropped).";
[M/%;]

"R: n -- random 0 to n-1: r = r x 75 + 74 (a linear congruential generator, wrapping at 16";
"   bits), then its high byte (r divided by 256, AND 255) taken modulo n.";
[R r@75*74+:r! 256/;255& %M]
"   Exactly: for a state of 0 to 32767 this is its high byte. Above that the state reads as";
"   negative and the division rounds toward zero, so the byte comes out one more than the";
"   high byte (255 turning into 0) unless the low byte is 0. It is still a number 0 to 255.";

"K: -- key. Wait for a key; while waiting, r is stirred, which is how the random numbers";
"   get a seed from the time the player takes to press a key.";
[K0 1(;r@1+r!1?:0=)]

"L: new line.";
[L13'10']

"C: row column -- move the cursor there (both from 0): /~ in a string takes them from";
"   under the string's address.";
[C"/~"$]

"X: -- flag  does piece p, turn g, fit at e,f? true = it hits something.";
"   This is the one place the shape masks are tested. m is the mask of shape p x 4 + g. v is";
"   a single bit that starts at 1 and doubles each time round, and k counts the bits 0 to 15.";
"   When m AND v is not 0 the box cell k is part of the piece. That cell lies at row f + k div";
"   4, column e + k mod 4 of the well, so its byte is at w + (f + k div 4) x 12 + e + (k mod";
"   4). If that byte is not 0 (a block or a wall), z is set to 1. z starts at 0 and is the";
"   result. All 16 bits are always scanned. There are no comments in the body: it runs 16";
"   times each time and it is called for every move.";
[X 0z! p@4*g@+2*t@+@ m! 1v! 0k! 1( m@v@&( f@k@4/;+12* e@+ k@4M+ w@+, ( 1z! 0) 0)
   v@2*v! k@1+:k! 16<) z@]

"Q: string -- draw the piece's four cells (piece p, turn o, at x,y) with that 2-character";
"   string. The same scan as in X: for every set bit k of the mask, the cursor goes to";
"   screen row y + k div 4 and screen column (x + k mod 4) x 2 and the string is";
"   printed. To erase a piece, draw it with space and dot; to draw it, with [] .";
[Q a! p@4*o@+2*t@+@ m! 1v! 0k! 1( m@v@&( y@k@4/;+ x@k@4M+2* C a@$ 0)
   v@2*v! k@1+:k! 16<)]

"T: -- flag  move to e,f,g if it fits. X says whether it hits; 0= turns that into fits. The";
"   copy of the flag (:) runs the block, which commits the new position to x y o. The";
"   flag stays: true if the piece moved.";
[T X0=:( e@x! f@y! g@o! 0)]

"U: -- flag  erase the piece, try the move e,f,g, and draw the piece again, wherever it is";
"   now (at the new place if it moved, else at the old one). The flag says whether it moved.";
[U " ."Q T "[]"Q]

"P: lock the piece into the well: the same scan once more, now storing a 1 in the well at";
"   each cell of the piece (the cell address is built as in X, from x, y and the bit k).";
[P p@4*o@+2*t@+@ m! 1v! 0k! 1( m@v@&( 1 y@k@4/;+12* x@+ k@4M+ w@+. 0)
   v@2*v! k@1+:k! 16<)]

"F: -- flag  is row j full? z starts at -1 (true) and becomes 0 if any of the ten cells,";
"   columns 1 to 10 (i), of row j is empty. The result is z.";
[F -1z! 1i! 1( j@12*i@+w@+,0=( 0z! 0) i@1+:i! 11<) z@]

"H: drop every row above j down by one, so row j is overwritten. Each pass of the outer";
"   loop copies row j - 1 to row j, column by column (i = 1 to 10), then moves j up one;";
"   it stops when j reaches 0. Then the top row, row 0, is cleared. H leaves j at 0.";
[H 1( 1i! 1( j@1- 12*i@+w@+, j@12*i@+w@+. i@1+:i! 11<) j@1-:j! 0>)
   1i! 1( 0i@w@+. i@1+:i! 11<)]

"Z: clear full rows. u is the row being checked, from 19 up to 1. j is set to u (F and H";
"   use j). If row u is full (the flag from F), H drops everything above it, so row u now";
"   holds what was above, and the line count l goes up by 1. The flag is copied (:) so that";
"   it can be used twice: the block runs when the row was full; ~ then reverses the flag, so";
"   u moves up by one only when the row was NOT full (after a clear the same row u is checked";
"   again, because a full row may have dropped into it). The loop ends when u reaches 0.";
[Z 19u! 1( u@j! F:( u@j! H l@1+l! 0)~( u@1-u! 0) u@0>)]

"D: draw the whole well and the score. Home the cursor (0 0C); for each row j (0 to 20)";
"   and column i (0 to 11) read the cell, double it and add the address of the string space-dot-[]-##";
"   to get its two characters: the first is printed from the copy of the address, the second";
"   is the next byte. A row ends with a new line. Then the text on the right (level, lines";
"   and keys) goes at screen column 29, rows 1 2 4 5 6, in one string: each /~ takes the";
"   next pair down, so the pair for row 1 is pushed last. /b and /l print level and lines.";
"   D does not draw the falling piece.";
[D 0 0C 0j! 1( 0i! 1( j@12*i@+w@+, 2* " .[]##"+ :,' 1+,' i@1+:i! 12<) L j@1+:j! 21<)
   6 29 5 29 4 29 2 29 1 29
   "/~Level /b/~Lines /l/~a d move   w rotate/~s down     space drop/~q quit"$]

"N: -- flag  a new piece at the top; true if it doesn't fit (game over). p is a random";
"   piece 0 to 6, turn 0, in column 4, row 0. The position is also tried (e f g) and X tests";
"   it; its flag is the result. N does not draw the piece.";
[N 7R p! 0o! 4x! 0y! x@e! y@f! o@g! X]

"G: gravity: one row down, or lock, clear lines and start a new piece. Try one row down";
"   (U draws the result). The flag, reversed with 0=, is true if the piece could not move.";
"   Then the block: lock it (P), clear full rows (Z), level b = lines divided by 10 (the";
"   quotient), frames per row s = 48 - 4 x level but at least 4, redraw the well and the";
"   score (D), start a new piece (N: if it does not fit, set d, the game over flag) and draw";
"   it. A gravity step is rare (about once a second), so the short comments cost nothing.";
"   Speed: s + 1 frames a row, so 49 frames (about 1 s) at level 0, 4 fewer each level,";
"   never under 5 frames (the cap is s = 4, reached at level 11).";
[G x@e! y@1+f! o@g! U 0=( P Z l@10/;b! 48 b@4*- s! s@4<( 4s! 0) D N( 1d! 0) "[]"Q 0)]

"Y: act on the key in c (a key press is rare compared with frames, so it is cheap to run).";
"   a and d: try one column left or right. w: try the next turn (o + 1 AND 3). s: gravity,";
"   as if the timer had run out. space: move down while U says it moved, then G, which";
"   can no longer move the piece and locks it. q: set the game over flag. In every move";
"   the try is e f g, the flag from U is not needed, and ; drops it.";
[Y c@97=( x@1-e! y@f! o@g! U; 0) c@100=( x@1+e! y@f! o@g! U; 0)
   c@119=( x@e! y@f! o@1+3&g! U; 0) c@115=( G 0)
   c@32=( 1( x@e! y@1+f! o@g! U ) G 0) c@113=( 1d! 0)]

"Main program";
"";
"Seed the random state with 0 (the first key wait stirs it). Allocate the well, 12 x 21 = 252";
"bytes, and the shape table, 28 x 2 = 56 bytes.";
0r!
252_w! 56_t!

"The shape masks, as decimal numbers, four turns per piece in the order I, O, T, S, Z, J, L.";
"All 28 numbers go onto the stack, the last one on top, so the loop below stores them from";
"the end: i counts down from 27 to 0, and each pass stores the top of the stack in cell i";
"of t. The loop runs while i is above -1.";
240 17476 240 17476  102 102 102 102  39 562 114 610  54 561 54 561
99 306 99 306  113 550 1136 802  116 1570 368 547
27i! 1( i@2*t@+! i@1-:i! -1>)

"Title screen. Wait for a key (the wait seeds the random generator) and drop it.";
"/{TETRIS"$ L L
"a d move, w rotate, s down, space drops, q quits."$ L "Press a key."$ L K;

"Game loop: one pass per game.";
1( "Fill the well: for each of the 252 cells i, x = i mod 12 and y = i div 12. A cell is a";
   "wall (2) if it is in column 0 or 11 or on row 20, else 0 (empty). The 0 is pushed first;";
   "the block drops it and leaves 2. The flag is the OR of the three tests.";
   0i! 1( i@12M x! i@12/; y! 0 x@0= x@11=| y@20=|( ; 2 0) i@w@+. i@1+:i! 252<)
   "Reset lines, level, game over flag and frame counter, and set the gravity to 48 frames.";
   "Clear the screen (/{), draw the well, start the first piece (N, its flag is dropped) and";
   "draw it: the box is drawn with [] by Q, which uses x, y and o, set by N.";
   "/{"$ 0l! 0b! 0d! 0n! 48s! D N; "[]"Q
   "The frame loop. Each pass takes about 20 ms: 20? waits up to 20 ms for a key and gives";
   "the key, or 0 if none came. If a key came, Y acts on it. Then the frame count n goes up";
   "by one; when it is above s (frames per row), n restarts at 0 and gravity runs (G). The";
   "loop ends when G (or the key q) has set d. It has no comments, to keep a frame short.";
   1( 20? c! c@( Y 0) n@1+:n! s@>( 0n! G 0) d@0=)
   "Game over: show the message on row 22, ask to play again. Any other key than y ends.";
   22 0C "GAME OVER. Lines: /l   Play again? (y//n) "$ K 121= )
L

"Show the cursor again (/|): delete the next line too if the one at the start was deleted.";
"/|"$
