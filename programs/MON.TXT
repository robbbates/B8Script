"  XXXX         show 16 bytes from XXXX, in hex and as text";
"  Return       show the next 16";
"  XXXX.YYYY    show XXXX to YYYY (a key stops it)";
"  XXXX: hh hh  store bytes from XXXX (a line that starts with : goes on from there)";
"  XXXXR        run the machine code at XXXX (see the CPU's appendix in the spec)";
"  ?  help      Q  quit";
"It starts where free memory starts, at the heap top. Which addresses are safe to change";
"  depends on the machine: the program, the interpreter and the stacks are memory too.";
"Variables: a the address shown next, e the end of a range, s where the next byte is";
"  stored, t the place in the typed line, v a number read and h its digit count, f set";
"  to quit, n bytes on a line, i a counter, z a remainder, b a byte.";

"D ( n -- ): one hex digit. H ( n -- ): a cell in 4 hex digits. B ( n -- ): a byte in 2.";
