"BREAKOUT for B8Script. Knock out the wall of bricks with the ball. Three balls.";
"Keys: a and d move the paddle 4 cells, space serves the ball, q quits.";
"Where the ball meets the paddle sets its slope: 2 or 1 cells across for each";
"row, to the left on the left half of the paddle, to the right on the right half.";
"Real time: each frame waits up to 20 ms for a key (20?), and the ball moves one";
"step every 5 frames at first, down to every 2 as the wall goes. Only the cells";
"that change are drawn. The field is 48 x 20 in a frame at the top left; 80 x 24.";

"How to read the notes. ( a b -- c ) is a stack effect: what a word takes and leaves,";
"the top of the stack on the right. [X ... ] defines word X; calling X runs its body.";
"Every comment is a string that is dropped at once (the semicolon), so it does nothing,";
"but it still takes a little time to read. So the words that run on every frame or every";
"ball step (the main frame loop and T) have no comments inside them: their notes come";
"just before them.";

"The plan in short:";
"  1. The game is a loop of frames. Each frame waits up to 20 ms for a key and acts on it.";
"  2. A frame counter n makes the ball move only every v frames: T is the ball step.";
"  3. The ball is one character on the screen; moving it means rubbing it out and drawing";
"     it again. The wall of bricks is a table of 72 bytes, looked up from the ball cell.";
"  4. When bricks go, v falls from 5 to 2, so the ball speeds up.";

"Hide the cursor while it runs: delete the next line for a terminal without ESC [?25l.";
"/[[?25l"$

"Variables";
"  k  the bricks, 6 rows of 12 bytes (1 there, 0 gone); brick row j is field row j+2";
"  b  bricks left   x y  the ball (0-47, 0-19)   d e  its step across and down";
"  p  the paddle's left end (0-40, on row 19, 8 wide)   f  the ball is in play";
"  v  frames per ball step   n  frame counter   s  score   l  balls left";
"  g  0 playing, 1 out of balls, 2 wall cleared, 3 quit   c  key";
"  o  where the paddle goes   a i j  scratch   r  random state";

"Screen layout. The border frame is drawn from line 2: a top border on line 2 and side";
"walls (a bar) at columns 1 and 50 on lines 3 to 22. Inside it is the field of 48 columns";
"(x from 0 to 47) and 20 rows (y from 0 to 19). Field cell (x,y) is at screen line y+3,";
"column x+2. The ball starts one row above the paddle row 19, i.e. on row 18.";
"Bricks. Each brick is four characters wide, written [==] , so 12 bricks fill 48 columns.";
"Brick row j (0 to 5) is on field row j+2, screen line j+5. Brick table k: byte number";
"j*12 + (column of the ball divided by 4); it is 1 while the brick stands and 0 when gone.";
"Ball motion. d is the step across (-2 to 2) and e the step down (-1 up, 1 down);";
"the ball moves by (d,e) in each step, so a slope of 2 or 1 cells across for each row.";
"The right-hand panel (columns 54 onwards) shows score, balls left and the keys.";

"Routines";

"M: ( n d -- r )  the remainder of n by d. Divide leaves quotient and remainder;";
"   the swap and drop keep the remainder.";
[M/%;]

"R: ( n -- 0..n-1 )  a random number below n, from the state in r.";
"   r@75*74+:r! is a linear congruential step: r becomes r*75+74 (a cell wraps at 65536)";
"   and a copy is left. The low bits of such a generator are poor, so dividing by 256";
"   and masking with 255 takes the upper byte (0 to 255) of the new state. Then the swap";
"   puts n on top for M, which reduces that byte to 0..n-1.";
[R r@75*74+:r! 256/;255& %M]
"   Exactly: for a state of 0 to 32767 this is its high byte. Above that the state reads as";
"   negative and the division rounds toward zero, so the byte comes out one more than the";
"   high byte (255 turning into 0) unless the low byte is 0. It is still a number 0 to 255.";

"K: ( -- key )  wait for a key, and stir the random state while waiting.";
"   A dummy 0 starts the loop. Each pass drops the previous test value, adds 1 to r,";
"   takes a quick look for a key (1?, gives 0 if none), and keeps a copy for the test.";
"   The loop ends when the value is not 0, leaving the key. How long the player took";
"   decides r, so the first serve differs from game to game.";
[K0 1(;r@1+r!1?:0=)]

"L: new line (CR then LF).";
[L13'10']

"Screen. C: clear   Y: row column -- move the cursor   E: clear to the end of the line";
"C clears the screen and homes the cursor (ESC [2J then ESC [H; in a string, ESC is";
"written as a slash followed by a left bracket).";
[C"/[[2J/[[H"$]
"Y sends ESC [ row ; column H. 27' and 91' print ESC and [. The swap brings the row";
"to the top to print first, then 59' is the semicolon, # prints the column, 72' is H.";
"Rows and columns count from 1.";
[Y27'91'%#59'#72']
[E"/[[K"$]

"P: ( x y -- )  move the cursor to that cell of the field: line y+3, column x+2.";
"   3+ adds 3 to y; the swap brings x up for 2+; Y takes the line first.";
[P 3+ % 2+ Y]

"O: draw the ball (character 79, a letter O) at x,y.   Z: rub it out (a space).";
[O x@y@P 79']
[Z x@y@P 32']

"S: the score and the balls left, in the right-hand panel on lines 3 and 4.";
"   E clears the rest of each line, so a shorter number leaves no old digits behind.";
[S 3 54Y "Score "$ s@# E 4 54Y "Balls "$ l@# E]

"D: draw the field, the wall, the paddle and the keys. It runs once per game.";
"   Line 2: the top border. Then j from 3 to 22: a bar at column 1 and at column 50.";
"   Then the bricks: for each of the 6 rows j, go to line j+5, column 2 and print the";
"   four characters [==] twelve times (the counter 12 is kept on the stack, 1-: ) counts";
"   it down and the ; drops it). Then the paddle on field row 19 (8 equals signs), the";
"   score and balls, the title and the three help lines.";
[D C 2 1Y "+------------------------------------------------+"$
   3j! 1( j@1Y "|"$ j@50Y "|"$ j@1+:j! 23<)
   0j! 1( j@5+ 2Y 12 1( "[==]"$ 1-: ); j@1+:j! 6<)
   p@19P "========"$ S 1 2Y "BREAKOUT"$
   7 54Y "a d   move the paddle"$ 8 54Y "space serve"$ 9 54Y "q     quit"$]

"H: serve: the ball goes up from the paddle, to the left or the right";
"   f is set (in play) and the step down e is -1 (up). 2R gives 0 or 1, doubled and";
"   less 1 is -1 or 1: the step across d, left or right.";
[H 1f! -1e! 2R2*1- d!]

"A: put the ball on the paddle: x is the paddle's left end plus 3, y is row 18.";
[A p@3+x! 18y!]

"W: move the paddle 4 cells to o, and the ball with it while it isn't in play.";
"   Only the 4 cells at each end change";
"   If o equals p nothing is to move: leave at once (the break is the guard \).";
"   If the ball is not in play (f is 0), rub it out first (Z). The paddle is 8 cells";
"   p to p+7 on row 19. Moving right (o above p): blank the 4 cells at the left end";
"   p to p+3 and draw 4 equals signs at p+8. Moving left (o below p): draw them at o";
"   (the new left end) and blank the 4 cells at o+8. Then p becomes o, and if the ball";
"   is not in play it is put back on the paddle (A) and drawn (O).";
[W p@o@=\ f@0=( Z 0) o@p@>( p@19P "    "$ p@8+19P "===="$ 0)
   o@p@<( o@19P "===="$ o@8+19P "    "$ 0) o@p! f@0=( A O 0)]

"U: act on the key in c";
"   a (97): the target o is p-4, but not below 0. The idiom p@4- :0<( ; 0 0) is a clamp:";
"   if the copy is below 0 it is dropped and 0 pushed (the last 0 is the block's flag).";
"   d (100): the target is p+4, but not above 40 (so the paddle's right end stays at 47).";
"   Each of them stores the target in o and calls W.";
"   Space (32) when the ball is not in play (f is 0): serve (H). q (113): g becomes 3.";
[U c@97=( p@4- :0<( ; 0 0) o! W 0) c@100=( p@4+ :40>( ; 40 0) o! W 0)
   c@32= f@0=&( H 0) c@113=( 3g! 0)]

"T: the ball takes a step: off the walls, into a brick (gone, and back down) or";
"   onto the paddle (back up, at a slope set by where it lands); below it, lost";
"   This word runs on every ball step, so it has no comments inside. Its parts, in order:";
"   1. Z rubs the ball out. The new column i is x+d. The test x@d@+ :0< {:}%47>| asks";
"      is it below 0 or above 47 ({:}% is over, a copy of the value under the top).";
"      If so (the block): drop it, reverse d (d times -1), compute x+d again. Store in i.";
"   2. The new row j is y+e. Only the top needs a test (below 0): bounce the same way.";
"      Falling past the bottom is handled below. Store in j.";
"   3. A brick? j@1> j@8<& is j from 2 to 7, the brick rows. The brick's byte is at k +";
"      (j-2)*12 + (i divided by 4), kept in a. If it is not 0 (a@,): set it to 0, one";
"      brick fewer (b), score 8-j (higher rows score more), blank the four cells of the";
"      brick: its left end is (i divided by 4) times 4, on row j. Reverse e (the ball goes";
"      back), and put the ball's old place back in i and j so that it does not move";
"      this step. Show the score (S).";
"   4. The paddle? j@19= i@p@< i@p@7+>| 0=& is row 19 and i not left of p and not right";
"      of p+7. Then e becomes -1 (up). The slope: i-p (0 to 7) halved gives 0 to 3, which";
"      picks a character from ABDE. Taking away 67 turns A B D E (65 66 68 69) into";
"      -2 -1 1 2: the left half leans left, the right half leans right, the middle gently,";
"      the ends steeply. d is set to that. The ball stays where it was this step.";
"   5. Lost? j@19> is true when the ball reached row 20, below the paddle row. The flag is";
"      copied, so one copy runs the block and the other exits T at once (the break).";
"      The block: not in play (f is 0), one ball fewer (l); if none is left, g is 1.";
"      Then A O S put the next ball on the paddle, draw it and show the score.";
"   6. Otherwise the ball moves to i,j (stored in x,y) and is drawn (O). The speed: the";
"      bricks left b, divided by 24 (the quotient only) plus 2, is stored in v: 72 bricks";
"      give 5, 48 to 71 give 4, 24 to 47 give 3 and fewer than 24 give 2 frames per step.";
"      When no bricks are left (b is 0), g becomes 2: the wall is cleared.";
[T Z x@d@+ :0< {:}%47>|( ; d@-1*d! x@d@+ 0) i! y@e@+ :0<( ; e@-1*e! y@e@+ 0) j!
   j@1> j@8<&( j@2- 12* i@4/;+k@+a! a@,( 0a@. b@1-b! s@8+j@-s! i@4/;4* j@P "    "$
      e@-1*e! x@i! y@j! S 0) 0)
   j@19= i@p@< i@p@7+>| 0=&( -1e! i@p@- 2/; "ABDE"+,67- d! x@i! y@j! 0)
   j@19>:( 0f! l@1-l! l@0=( 1g! 0) A O S 0)\
   i@x! j@y! O b@24/;2+v! b@0=( 2g! 0)]

"Main program";

"Make the brick table, 72 bytes, and start the random state at 0";
72_k! 0r!
"Title screen. K waits for a key (stirring r); the ; drops the key.";
C "BREAKOUT"$ L L "Knock out the wall with the ball. a and d move the paddle, space serves"$ L
"the ball, q quits. You have three balls."$ L L "Press a key."$ K;

"Outer loop: one game per pass. First set every brick to 1 (the table k, 72 bytes).";
"Then: 72 bricks left, score 0, 3 balls, g 0 (playing), f 0 (ball not in play), the";
"paddle at 20, the ball put on it (A), 5 frames per step, the frame counter 0, then draw";
"the whole screen (D) and the ball (O).";
1( 0i! 1( 1i@k@+. i@1+:i! 72<) 72b! 0s! 3l! 0g! 0f! 20p! A 5v! 0n! D O
   "The frame loop. Each pass is one frame and runs about 50 times a second, so it has no";
   "comments inside. In order:";
   "  20? waits up to 20 ms for a key and gives it, or 0 if none came. :(32| 0) folds a";
   "  key to lower case (32| sets bit 5) and leaves 0 alone. It is stored in c, and if it";
   "  is not 0, U acts on it (paddle, serve or quit).";
   "  n@1+:n! counts the frame. v@<0= is n not below v: then the counter goes back to 0";
   "  and, if the ball is in play (f), T takes one ball step. So the ball steps once";
   "  every v frames and the paddle can move on any frame.";
   "  g@0= is the loop test: go on while g is 0 (playing).";
   1( 20? :(32| 0) c! c@( U 0) n@1+:n! v@<0=( 0n! f@( T 0) 0) g@0=)
   "After the game: go to line 24 and say how it ended, if g is 1 or 2 (g is 3 for q,";
   "which says nothing), then the score and the question. E clears the line's remainder.";
   24 2Y g@1=( "Out of balls."$ 0) g@2=( "You cleared the wall!"$ 0)
   "  Score "$ s@# ". Play again? (y//n) "$ E K 121=)
C "Bye."$ L

"Show the cursor again: delete the next line too if the one at the start was deleted.";
"/[[?25h"$
