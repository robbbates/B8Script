"MASTERMIND for B8Script. Break a code of four digits, each 1 to 6, in ten tries.";
"Black = right digit in the right place. White = right digit, wrong place.";
"Keys: type four digits 1 to 6 for each guess; y or n at the end of a game.";

"Variables";
"  s g  secret and guess, 4 bytes each   b e  black and white pegs";
"  t  try number   i k  counters   c  key   x y  arguments of N";
"  p q n  used by C (and j, its counter)   r  random state";
"  s and g are heap blocks: s holds the code, one digit value 1-6 per byte;";
"  g holds the current guess in the same form (values, not ASCII characters).";

"Routines";

"M: ( n d -- n mod d ).  The divide word leaves quotient and remainder, with the";
"remainder on top; the drop ; throws the quotient away. Used by R.";
[M/%;]

"R: ( n -- 0..n-1 ).  A random number. r is a linear congruential generator:";
"  r = r * 75 + 74 (a 16-bit wrap), stored back (the : keeps a copy for use).";
"  Dividing by 256 and dropping the remainder keeps the quotient r div 256, and 255&";
"  cuts it to one byte, because the low bits of such a generator are the least";
"  random. Then % swaps the byte under n and M takes byte mod n.";
[R r@75*74+:r! 256/;255& %M]
"   Exactly: for a state of 0 to 32767 this is its high byte. Above that the state reads as";
"   negative and the division rounds toward zero, so the byte comes out one more than the";
"   high byte (255 turning into 0) unless the low byte is 0. It is still a number 0 to 255.";

"K: ( -- key ).  Wait for a key, and stir r while waiting. 0 is a dummy that the";
"  first pass drops. Each pass: drop the old value, add 1 to r, then look for a";
"  key with 1? (it gives the key or 0 at once). The : 0= makes a flag that is";
"  true while no key came, which repeats the loop. The key stays on the stack.";
"  So r depends on how long the player took, and the code differs each game.";
[K0 1(;r@1+r!1?:0=)]

"L: print a new line (CR LF).";
[L13'10']

"N: ( x y -- smaller ).  Minimum of two numbers. y! x! store them; if x < y";
"  then x replaces y; y@ is the result.";
[N y!:x! y@<( x@y! 0) y@]

"C: ( addr digit -- n ).  How many times the digit appears in the 4 bytes at addr.";
"  p is the address, q the digit, n the count, j the position 0-3.";
"  The loop 1( ... 4<) runs four times: j@ is dup-stored with : and compared.";
[C q!p! 0n! 0j!
   1( p@j@+,q@=( n@1+n! 0)    "if byte j equals the digit, count it";
      j@1+:j! 4<)
   n@]

"A: ( -- ).  Read a guess of four keys 1 to 6 into g, echoing each one.";
"  A key counts only if its ASCII code is above 48 and below 55 (c@48> c@55<&);";
"  anything else is ignored and read again. Then c@' echoes the character,";
"  c@48- turns it into the value 1-6 and g@i@+. stores it as byte i of g.";
"  The loop goes on while i is below 4.";
[A 0i! 1( K :c! 48> c@55<&( c@' c@48- g@i@+. i@1+i! 0) i@4<)]

"P: ( -- ).  Score the guess: blacks go in b, whites in e.";
"  Blacks: compare s and g byte by byte (s@i@+, g@i@+, =) and count equals.";
"  Whites: for each value k from 1 to 6 the number of pegs matched in total is";
"  the smaller of (times k is in the secret) and (times k is in the guess). The";
"  sum of those minimums over all k counts every right digit, black or not.";
"  The whites are that total minus the blacks (e@b@-e!).";
[P 0b! 0i! 1( s@i@+, g@i@+, =( b@1+b! 0) i@1+:i! 4<)
   0e! 1k! 1( s@k@C g@k@C N e@+e! k@1+:k! 7<)
   e@b@-e!]

"Main program";
"Start the random state at 0, then get two 4-byte blocks for the code and the guess.";
0r!
4_s! 4_g!
"Outer loop: one game per pass.  Each game starts on a clear screen (/{ clears it";
"and homes the cursor) with the title and rules (L is the new line word), so a";
"new game does not run on below the last one. The key that K waits for stirs r.";
"Then choose the secret: 6R1+ gives 1 to 6.";
1( "/{MASTERMIND"$ L L
   "I have picked four digits, each 1 to 6 (repeats allowed)."$ L
   "You have ten tries. Press a key to start."$ L K; L
   0i! 1( 6R1+ s@i@+. i@1+:i! 4<)
   "Inner loop: one try per pass, t is the try number, from 1.";
   "  Print the number, right-aligned (a space first if t is below 10), read the";
   "  guess (A), score it (P) and print the pegs. /t /b /e in a string print the";
   "  variables t b e. Go on while not cracked (b below 4) and t is still 10 or";
   "  less (t@11<) after the increment.";
   1t! 1( t@10<(" "$ 0) "/t: "$ A P
          "   /b black, /e white"$ L
          t@1+t! b@4< t@11<& )
   "After the loop: cracked, or out of tries (then reveal the code, digit + 48).";
   b@4=( "Cracked in "$ t@1-# " tries!"$ 0)
   b@4<( "Out of tries. The code was "$ 0i! 1( s@i@+,48+' i@1+:i! 4<) 0)
   "Ask again: the key is echoed and compared with y (121). True repeats the game.";
   L L "Play again? (y//n) "$ K :' L L 121= )
"Bye."$ L
