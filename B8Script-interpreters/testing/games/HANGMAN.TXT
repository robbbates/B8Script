"HANGMAN for B8Script. Guess the word one letter at a time; six misses and you hang.";
"Keys: a letter a to z to guess (anything else is ignored); y or n at the end.";

"Variables";
"  l  word list: twenty 7-letter words, 8 bytes apart";
"  w  address of the secret word      g  26 flags, one per letter tried";
"  m  misses   u  letters still hidden   c  key   f  found flag   i  counter";
"  r  random state, stirred while waiting for keys";
"  g is a heap block of 26 bytes: byte (letter - 97) is 1 once that letter";
"  has been tried, else 0.  The word list is a string in the program text.";

"Routines";

"M: ( n d -- n mod d ), the remainder of the division.";
[M/%;]

"R: ( n -- 0..n-1 ).  Random number: r = r * 75 + 74 (16-bit wrap), kept in r,";
"  then one byte of it (r div 256, cut by 255&) is reduced with M.";
[R r@75*74+:r! 256/;255& %M]
"   Exactly: for a state of 0 to 32767 this is its high byte. Above that the state reads as";
"   negative and the division rounds toward zero, so the byte comes out one more than the";
"   high byte (255 turning into 0) unless the low byte is 0. It is still a number 0 to 255.";

"K: ( -- key ).  Wait for a key while adding 1 to r on every pass, so r depends";
"  on how long the player waits. 1? looks for a key and gives it or 0; the";
"  loop repeats while the dup : 0= says there was none. The 0 is a dummy that";
"  the first pass drops.";
[K0 1(;r@1+r!1?:0=)]

"L: print a new line (CR LF).";
[L13'10']

"S: ( -- ).  Show the word, letters found or an underscore, and count the hidden";
"  ones in u.  For each of the 7 positions i:";
"    c = the letter w@i@+, ;  c@97-g@+, = the tried flag for that letter.";
"    The flag is dup-ed by : so two tests use it: if true, print the letter;";
"    then 0= (not tried) is true, so print _ (95) and count it in u.";
"    Then print a space and go on while i is below 7.";
[S 0u! 0i! 1( w@i@+,c!
     c@97-g@+,:( c@' 0) 0=( 95' u@1+u! 0)
     32' i@1+:i! 7<)]

"T: ( -- ).  Show the letters tried so far: for each of the 26 flags that is set,";
"  print the letter, 97 + its number.";
[T 0i! 1( g@i@+,( i@97+' 0) i@1+:i! 26<)]

"D: ( -- ).  Draw the whole screen: clear it, title, gallows, the word, the";
"  misses and the tried letters. The figure grows with m, the misses:";
"    1 head O, 2 body |, 3 left arm, 4 right arm, 5 left leg, 6 right leg.";
"  Each part is a block m@n> ( ... 0) that prints only when m is above n. The";
"  string for an arm or leg shows a slash in the code, written twice as an escape.";
"  The rows are the top bar,";
"  the head row, the arms and body row, the legs row, and the ground.";
[D "/[[2J/[[H"$ "H A N G M A N"$ L L
   "  +---+"$ L
   "  |   "$ m@0>( "O"$ 0) L
   "  |  "$ m@2>( "//"$ 0) m@1>( "|"$ 0) m@3>( "\"$ 0) L
   "  |  "$ m@4>( "//"$ 0) " "$ m@5>( "\"$ 0) L
   "  |"$ L "=====" $ L L
   "  "$ S L L "Misses: "$ m@# " of 6     Tried: "$ T L L]

"G: ( -- ).  Read a letter and play it; ignore anything else, or a repeat.";
"  Outer test: the key is above 96 and below 123, a lowercase letter.";
"  Next test: its flag is 0, not tried yet.  Then:";
"    set the flag to 1 (the 1 and the address are stored with .);";
"    f = 0, then search the 7 positions of the word for the letter, f = 1 if";
"    found; if f is still 0 it is a miss, so m is increased.";
[G K c! c@96> c@123<& ( c@97-g@+,0= (
     1 c@97-g@+.  0f! 0i! 1( w@i@+,c@=( 1f! 0) i@1+:i! 7<)
     f@0=( m@1+m! 0)
   0) 0)]

"Main program";
"Start the random state at 0.";
0r!

"The word list: twenty words of seven letters, each followed by a space, so that";
"  every word starts 8 bytes after the one before it. The first three lines are";
"  comments that show the list; the last string is the real one, and l! stores";
"  its address in l.";
"abandon balloon capture diamond example fiction gallery harvest";
"journey kingdom lantern mystery network orchard pyramid quarter";
"rainbow science thunder volcano";
"abandon balloon capture diamond example fiction gallery harvest journey kingdom lantern mystery network orchard pyramid quarter rainbow science thunder volcano "l!
"The 26 letter flags.";
26_g!

"Title screen; K waits for a key (and seeds r from the waiting time).";
"/[[2J/[[H"$ "HANGMAN. Press a key to start."$ L K;

"Outer loop: one game per pass.  Clear the flags to 0.";
1( 0i! 1( 0g@i@+. i@1+:i! 26<)
   "Choose a word: 20R is 0 to 19, 8* is its offset in the list, l@+ its address.";
   "  Misses start at 0.";
   20R 8* l@+ w!  0m!
   "Guess loop. D draws (and S inside it sets u, the hidden count). The game is";
   "  over when u is 0 (won) or m is above 5 (lost): then ~ makes the flag false.";
   "  If not over, G plays one letter. The flag is dup-ed with : so one copy";
   "  guards G and the other, left on the stack, is the loop flag.";
   1( D u@0= m@5>| ~:( G 0) )
   "Result: won, or lost and show the word.";
   u@0=( "You got it!"$ 0) u@( "Hanged! The word was "$ 0i! 1( w@i@+,' i@1+:i! 7<) 0)
   "Ask for another game: the key is echoed and compared with y (121).";
   L L "Play again? (y//n) "$ K :' L 121= )
"Bye."$ L
