"LEDIT for B8Script: a small line editor for text files.";
"It needs CP/M on a Z80 or an 8080, as it reads and writes the file through the BDOS: run";
"  it with a CP/M runner, B8S LEDIT.B8S FILE.TXT. With no name after the program's, it";
"  asks for one. On any other build it says so and ends.";
"Lines are counted, not numbered, as in the line editor the spec suggests. At the *";
"  prompt, ended with Return:";
"  n text   the text goes in as line n, and the lines from n on move down; a number past";
"           the end adds it at the end. The one character after n is not stored.";
"  n        line n is taken out.";
"  nI  I    insert mode from line n, or after the last line: each line typed goes in at";
"           the next number, until an empty line.";
"  nL  L    list 20 lines from line n, or from line 1.";
"  W        write the file: NAME.$$$ is written and closed, NAME deleted, and NAME.$$$";
"           renamed NAME, so a write that fails leaves the old file as it was.";
"  Q        quit, after asking whether to save first: y saves and quits, n quits, any";
"           other key goes back.";
"  5I and 5L are commands only with nothing after the letter: 5Lunch puts unch in line 5.";
"A file that is not there is a new one, made by W. The whole text is held in memory, from";
"  the heap top up to the BDOS; a file too big for it is not edited at all (a write would";
"  lose its end). The text ends at the first ^Z, every line ends with CR LF (one is added";
"  to a last line without), and a line is counted at each LF.";
"The file kit: B calls the BDOS, N puts a name in an FCB, A finds the name on the command";
"  line. Its variables: b the gateway's code, f the FCB (36 bytes), d the record buffer,";
"  which here is the text itself: records are read into it and written from it; t, i and";
"  c scratch.";
"Variables of LEDIT: e the end of the text, l the limit of memory, g the temporary FCB, m";
"  and s the move and the scanner's code, k a line's number (set by F), n the number typed";
"  and h whether one was, x whether the line ends after the command letter, j the line";
"  insert mode is at, q set to quit, o set by a good write, r by a line that went in, z a";
"  failure, and v, w, y scratch.";
