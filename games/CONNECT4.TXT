"CONNECT FOUR for B8Script. You are X and move first; the machine is O.";
"It takes a win when it sees one, blocks yours, and otherwise plays at random.";
"Keys: 1 to 7 drops your piece into that column. At the end, y plays again.";

"How it works, in short: the board is a heap block of bytes. A move drops a piece";
"to the lowest empty cell of a column. To see whether a piece makes four, the";
"program counts same-coloured neighbours outwards from the new piece in both";
"directions of each of four lines (across, down and the two diagonals). The";
"machine finds its move by trying every column: first as itself (would this win?),";
"then as you (would this let you win? then block it), else a random column.";

"Variables";
"  b  board: 9 x 8 bytes, a border of zeros around 7 x 6 cells; cell = y*9+x";
"  v  piece being placed (1 = X, 2 = O)   c  column   z  cell index";
"  w  win flag   h  pieces played   g  game over   o  winner (0 none)";
"  a k  used by A   e  used by X   q d n  used by U   x y  used by D and F";
"  r  random state (set in the main program, stirred by K)";

"Board layout. b is a block of 72 bytes holding 9 columns (x = 0 to 8) and 8 rows";
"(y = 0 to 7), so the cell at column x, row y is at b + y*9 + x. Each byte is";
"0 empty, 1 X, 2 O. Only x = 1 to 7 and y = 1 to 6 are playing cells; the outer";
"ring (x = 0 and 8, y = 0 and 7) is never written, so it stays 0. Row 1 is the";
"top of the board, row 6 the bottom, and a piece falls towards larger y.";
"The ring matters: a line count walking off the board meets a 0, which is never";
"equal to a piece (1 or 2), so it stops there, and no edge tests are needed.";
"Nine columns (not eight) make a step of +1 from column 8 land on a ring cell";
"of the next row, never on a playing cell, so rows cannot wrap into each other.";

"Routines";

"M: ( n d -- n mod d ).  Division (the slash) leaves quotient and remainder (remainder on";
"top); then % swaps them and ; drops the quotient, so only the remainder is left.";
[M/%;]

"R: ( n -- 0..n-1 ).  A random number. r is a linear congruential generator:";
"  r = r * 75 + 74 (16-bit wrap); the : keeps a copy of the new r for the next";
"  step and r! stores the other. Dividing by 256 (and dropping the remainder)";
"  keeps r div 256 (about the top byte, the best bits); 255& cuts it to 0-255.";
"  Then % brings n on top and M takes byte mod n.";
[R r@75*74+:r! 256/;255& %M]
"   Exactly: for a state of 0 to 32767 this is its high byte. Above that the state reads as";
"   negative and the division rounds toward zero, so the byte comes out one more than the";
"   high byte (255 turning into 0) unless the low byte is 0. It is still a number 0 to 255.";

"K: ( -- key ).  Wait for a key, stirring r while waiting, so the random numbers";
"  depend on the player's timing. The 0 is a dummy that the first pass drops.";
"  Each pass: drop the old value, add 1 to r, then 1? looks for a key (it gives";
"  the key, or 0 at once if none). The : 0= makes a flag, true while no key came,";
"  so the loop goes on; the key itself stays on the stack when it ends.";
[K0 1(;r@1+r!1?:0=)]

"L: ( -- ).  New line: CR (13) then LF (10).";
[L13'10']

"F: ( column -- index )  the index of the cell a piece would land in, or 0 if the";
"  column is full. Drops from the bottom row (y = 6) upwards: while the cell";
"  at y is occupied, step y up by one.";
[F c! 6y!
   "Loop: fetch the byte at b + y*9 + c. The : copies it for the ( test; if it is";
   "non-zero (occupied) the body lowers y by 1. The original byte is left under";
   "the closing ) and is the loop flag: occupied repeats, empty (0) ends.";
   1( y@9*c@+b@+,:( y@1-y! 0) )
   "Now y is the landing row, or 0 (the ring) when the column was full. The :(";
   "keeps a copy of y as the test; when y is not 0 the body replaces the other";
   "copy with y*9+c. When y is 0 that 0 simply stays as the result.";
   y@:( 9*c@+ 0)]

"U: ( start step -- n )  how many cells in a row, starting one step from start and";
"  going on in that direction, hold piece v. q is the position, d the step.";
"  The start cell itself is not counted. The loop ends at the first cell that";
"  differs, the ring included.";
[U d! q! 0n!
   "Each pass: move q by d; fetch that cell; compare with v. The : ( counts a hit";
   "(n + 1) and the comparison flag left behind repeats the loop on a hit.";
   1( q@d@+q! q@b@+,v@=:( n@1+n! 0) )
   n@]

"X: ( step -- )  set w if the line through z in this direction (and its opposite)";
"  has four of piece v. e is the step.";
[X e!
   "Count forwards from z by e, and backwards by 0 - e (0e@- is the negated step).";
   "The cell z itself is not counted, so three or more others (2>) make four.";
   z@e@U z@0e@-U + 2>( 1w! 0)]

"W: ( -- flag )  does the piece v just placed at cell z make four in a line?";
"  The steps are 1 (across), 9 (down: one whole row), 10 (diagonal down-right)";
"  and 8 (diagonal down-left); X also tries the opposite direction of each.";
[W 0w! 1X 9X 10X 8X w@]

"T: ( column -- flag )  would piece v win by dropping into that column?";
"  It really places the piece, tests, then takes it away again.";
[T
   "The 0 is the result for a full column; % puts the column on top for F.";
   0 %F z!
   "If z is not 0: drop the 0, place v at z, run W (flag left on the stack),";
   "then clear the cell again. If z is 0 the block is skipped and 0 remains.";
   z@( ; v@z@b@+. W 0z@b@+. 0)]

"A: ( -- column )  the machine's choice. a is the choice so far (0 = none yet).";
"  Three steps, each only if a is still 0:";
"  1  play as O (v = 2): the first column in which O wins at once;";
"  2  play as X (v = 1): the first column in which you would win, to block it;";
"  3  otherwise a random column, retried until the column is not full.";
"  Note v is left at 1 after step 2; the main program sets it back to 2.";
[A 0a!
   "Step 1. k counts columns 1 to 7: if k wins and a is still empty, a = k.";
   "k@1+:k! 8< adds 1, stores it, and repeats while k is below 8.";
   2v! 1k! 1( k@T( a@0=( k@a! 0) 0) k@1+:k! 8<)
   "Step 2: the same search with v = 1, only if step 1 found nothing.";
   a@0=( 1v! 1k! 1( k@T( a@0=( k@a! 0) 0) k@1+:k! 8<) 0)
   "Step 3: 7R1+ is a random column 1 to 7; :a! keeps it as a; F gives 0 when that";
   "column is full, and 0= makes that the repeat flag.";
   a@0=( 1( 7R1+ :a! F 0=) 0)
   a@]

"H: ( -- )  read a legal column into c. A legal key is 1 to 7 and its column must";
"  not be full.";
[H
   "K gets a key; 48- turns the character into a number (key 1 gives 1) in c.";
   "c@0> c@8<& is true for 1 to 7. The : ( copies that flag; when it is true, drop";
   "it and leave F of the column (0 if full). Otherwise the false flag is left.";
   "Either way 0= makes the loop flag: repeat when the key is bad or column full.";
   1( K 48- c! c@0> c@8<&:( ; c@F 0) 0= )]

"P: ( -- flag )  drop piece v into column c, and say whether it makes four.";
"  z is set by F to the landing cell; the piece is stored there with . (a byte).";
[P c@F z! v@z@b@+. W]

"D: ( -- )  draw the board. Row 1 is printed first, so it is the top.";
[D
   "Clear the screen, home the cursor, title, a blank line, the column numbers.";
   "/[[2J/[[H"$ "CONNECT FOUR"$ L L "  1 2 3 4 5 6 7"$ L
   "Each of the 6 rows (y = 1 to 6): a space, then for x = 1 to 7 a space and the";
   "character from the string at the cell. A cell value 0, 1 or 2 is added to the";
   "address of the string and fetched with , to give a dot, X or O.";
   1y! 1( 32' 1x! 1( 32' b@y@9*+x@+, ".XO"+,' x@1+:x! 8<) L y@1+:y! 7<)
   " ---------------"$ L L]

"Main program";
"Seed the random state with 0 (K stirs it) and allocate the 72-byte board.";
"_ returns the old heap top, the address of the new block, and b! keeps it.";
0r!
72_b!
"Outer loop: one game per pass. First clear all 72 board bytes.";
1( 0x! 1( 0b@x@+. x@1+:x! 72<)
   "No pieces played, game not over, no winner. Show the empty board.";
   0h! 0g! 0o!
   D "Press 1-7 to drop your piece."$ L
   "Inner loop: your move, then the machine's, until g is set.";
   "Your move: v = 1; H reads a column; P drops and tests for four. On a win set";
   "g and winner o = 1. Then count the piece; more than 41 played means the board";
   "(42 cells) is full, a draw, so g is set (o stays 0).";
   1( 1v! H P( 1g! 1o! 0) h@1+h! h@41>( 1g! 0)
      "If the game goes on, the machine plays: draw, announce, A chooses a column";
      "into c, v = 2 (A leaves it at 1), P drops. A win sets g and o = 2; a full";
      "board sets g.";
      g@0=( D "Thinking..."$ A c! 2v! P( 1g! 2o! 0) h@1+h! h@41>( 1g! 0) 0)
      "Redraw, and while the game goes on say what the machine played (c is its";
      "column), then ask for the next move. The loop repeats while g is still 0.";
      D g@0=( "I played "$ c@# ". Your move (1-7): "$ 0)
      g@0= )
   "Result by winner: o is 1, 2 or still 0 (draw).";
   o@1=( "You win!"$ 0) o@2=( "I win!"$ 0) o@0=( "A draw."$ 0)
   "K waits for a key, : ' echoes it; 121 is y, and equal makes the repeat flag.";
   L L "Play again? (y//n) "$ K :' L 121= )
"Bye."$ L
