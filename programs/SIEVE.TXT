"SIEVE for B8Script: the BYTE benchmark (Jim Gilbreath, BYTE, September 1981).";
"Each pass finds the odd primes from 3 to 16383 by the sieve of Eratosthenes: flag i";
"  stands for 2i+3, and 1899 of the 8191 flags stay set. Type how many passes, then time";
"  them with a watch to compare machines, builds, or a checked build with an unchecked one.";
"Written for speed, with the algorithm unchanged:";
"  - A flag is found by an offset k from the end, i = k+8191, so k runs from -8191 up";
"    to 0 and the loops test it for nothing more than 0 (with ) or 0<), no 8191<.";
"  - The flags are set four at a time, by two cell stores of -1 (two bytes each).";
"  - A flag still set calls P: a ( that skips its block reads every character of it,";
"    so a short block (P0) is skipped fast, and most flags aren't primes.";
"  - Values stay on the stack where they can: a variable costs two steps (x@).";
"Variables: f the flags (8192 bytes on the heap: the last is set but never used), e";
"  and g the ends (f+8191, f+8192), p the prime, c the count of primes, n passes left,";
"  v used by N.";

"N ( -- n ): read a number typed with echo; it ends at the first key that is not a digit.";
[N0v!1(0?:48<\48-:#v@10*+v!1);v@]
"X ( k j -- k j' ): cross out every p-th flag from offset j on, while j < 0.";
[X1(:0%e@+.p@+:0<)]
"P ( k -- k ): flag k is set: p = 2i+3 = 2k+16385 is a prime. Count it, and cross out";
"  its multiples from offset k+p on (none if that is past the end).";
[P:::+16385+:p!+:0<(X0);c@1+c!]

"The flags, then the question.";
8192_f! f@8191+e! f@8192+g!
"SIEVE: the BYTE benchmark. Passes? "$ N n! 13'10'

"Each pass: set every flag; then, for each flag still set, count a prime p and cross";
"  out every p-th flag after it. A dot when the pass is done.";
n@( 1(
  -8192 1( :g@+:-1%!2+-1%! 4+:) ;
  0c! -8191 1( :e@+,(P0) 1+:) ;
  46' n@1-:n! ) 0)
13'10' c@#" primes"$ 13'10'
