"SPACE TRADER for B8Script. Buy low, fly, sell high. You have 40 days.";
"Each planet makes one good cheaply and pays well for another.";
"";
"How the game works: you start on Sol with 500 credits, a full tank of 20 fuel and an empty";
"hold (30 units). There are three goods (Food, Ore, Tech) and five planets. Every planet has";
"its own prices for the goods. Buy a good where it is cheap, travel to a planet where it";
"sells dear, and sell it there. Travel costs fuel (one unit per unit of distance) and days.";
"When day 40 is over, or you press q, the cargo is sold at the prices of the last planet and";
"you are told whether you made a profit over the 500 credits you began with.";
"Keys at the main prompt: b buy, s sell, f refuel, t travel, q quit.";
"";

"Variables";
"  m credits   f fuel (tank 20)   d day   p planet (0-4)   s message to show";
"     s is 0 or the address of a string. The next screen prints it once and clears it.";
"  e  base prices (3 cells)   k  prices here (3 cells)   q  cargo (3 cells)";
"  x  planet positions (5 cells)   u g  planet and good names, 8 bytes each";
"  c key   n number typed   i j o t v w  scratch   r random state";
"";
"Data layout. The three goods are numbered 0 1 2 inside the program (Food, Ore, Tech) and";
"1 2 3 on the screen. e, k and q are 6-byte heap blocks: cell j (at address base + 2j) belongs";
"to good j. x is a 10-byte block: cell j is the position of planet j on a line (distance";
"between two planets is the difference of their positions). u and g are strings of fixed";
"8-character names, so name j starts at address u + 8j (or g + 8j).";
"";

"Routines";

"M: n d -- n mod d. The division leaves quotient and remainder, the quotient is dropped.";
[M/%;]

"R: n -- a random number from 0 to n-1. r is a linear congruential generator: each call";
"   sets r to r x 75 + 74 (the cell wraps at 16 bits). The low bits of such a generator are";
"   poor, so the high byte of r is used: dividing r by 256 and keeping the quotient gives it,";
"   the AND with 255 keeps it as 0-255, the swap puts n back on top and M takes that modulo n.";
"   Stack, step by step: n, then n r, then n r' (r' is stored), then n byte, then byte n.";
[R r@75*74+:r! 256/;255& %M]
"   Exactly: for a state of 0 to 32767 this is its high byte. Above that the state reads as";
"   negative and the division rounds toward zero, so the byte comes out one more than the";
"   high byte (255 turning into 0) unless the low byte is 0. It is still a number 0 to 255.";

"K: -- key. Wait for a key, stirring r while we wait, so that the random numbers differ";
"   from game to game (the time the player takes to press a key seeds the generator).";
"   Each pass drops the previous 0, adds 1 to r and asks for a key with a 1 ms wait. The";
"   key (or 0 if none came) is copied and tested with 0=, so the loop repeats while the";
"   answer is 0. The key code is left on the stack.";
[K0 1(;r@1+r!1?:0=)]

"L: new line, CR then LF.";
[L13'10']

"A: n -- absolute value. :0< tests a copy of n: if it is negative the block multiplies n by";
"   -1 (the 0 before the bracket closes makes the block run once, not repeat). Else n stays.";
[A:0<( -1* 0)]

"Y: n -- print n left-aligned in a field of 6 columns, so the table columns line up.";
"   The number is printed first (dup, then #), then the spaces to pad are counted in o.";
"   o starts at 5 and loses 1 for every extra digit: n above 9, above 99, above 999 and";
"   above 9999 each subtract 1 (the last test uses up n, the others work on a copy).";
"   So a one-digit number is followed by 5 spaces, a four-digit number by 2, and so on.";
"   The final do-while prints a space, takes 1 off o and repeats while o is above 0.";
[Y :# 5o! :9>( o@1-o! 0) :99>( o@1-o! 0) :999>( o@1-o! 0) 9999>( o@1-o! 0)
   1( 32' o@1-:o! 0>)]

"Q: index names -- print the 8-character name number index from the string at names.";
"   The address of the name is names + 8 x index. Then w counts 0 to 7: each pass copies the";
"   address, adds w, fetches that byte and prints it. The address is dropped at the end.";
[Q %8*+ 0w! 1( :w@+,' w@1+:w! 8<) ;]

"N: -- n  read a number, digit by digit with echo, until Enter. n builds up in n:";
"   each digit key (code 48 to 57, tested as above 47 and below 58) is echoed and then";
"   n = n x 10 + (key - 48). Other keys (except Enter) are ignored and not echoed.";
"   The loop goes on until the key is 13: 13= gives a flag, and ~ turns it round.";
[N 0n! 1( K c! c@47> c@58<&( c@' n@10*c@48-+n! 0) c@13= ~) n@]

"H: -- the number of cargo units aboard: the sum of the three cells at q.";
"   q@@ reads the first cell (q holds the address of the block, @ again fetches the cell).";
[H q@@ q@2+@+ q@4+@+]

"G: -- j  ask for a good: the key 1 to 3 is echoed and turned into 0 to 2. If the key is";
"   not one of them j becomes -1, and the word leaves j. Callers check for a negative j.";
"   49- is key minus 49 (the code of 1): the space after the - makes it a subtraction.";
[G K :' 49- j! j@0< j@2>|( -1j! 0) j@]

"P: set the prices here, for the three goods. Each price is the base price of the good";
"   times a percentage, divided by 100. The percentage is 60 plus a random 0 to 79; it is";
"   lowered by 30 for the good this planet makes (the planet number modulo 3) and raised";
"   by 30 for the good it wants (the planet number plus 1, modulo 3). The first percent";
"   is kept on the stack while the two tests run and the 30- or 30+ changes it in place;";
"   the space in 30- 0) is needed, or the - would read as the sign of -0.";
"   j@2*e@+@ is base price j; the product is divided by 100, only the quotient kept, and";
"   stored in cell j of k.";
[P 0j! 1( 80R60+ p@3M j@=( 30- 0) p@1+3M j@=( 30+ 0)
          j@2*e@+@ * 100/; j@2*k@+! j@1+:j! 3<)]

"S: show the screen: the status, the goods table, the planets table, any message and the";
"   prompt. Everything is printed afresh after a clear screen and cursor home (/{ in";
"   a string). /d and /f print the day and the fuel. A slash in a string is written as";
"   two slashes, so the strings with fuel and hold show 20 and 30.";
[S "/{SPACE TRADER        Day /d of 40"$ L L
   "Credits "$ m@Y "Fuel /f//20   Hold "$ H# "//30"$ L
   "You are at "$ p@u@Q L L
   "The goods table: for j = 0 to 2, print the number j+1, the name, the price here";
   "(padded to 6 by Y) and the cargo aboard, one line each.";
   "   Good      Price  Aboard"$ L
   0j! 1( "   "$ j@1+# ". "$ j@g@Q j@2*k@+@Y j@2*q@+@# L j@1+:j! 3<) L
   "The planets table: number, name and distance, which is the difference of the two";
   "positions, made positive by A. The planet you are at shows distance 0.";
   "   Planet    Distance"$ L
   0j! 1( "   "$ j@1+# ". "$ j@u@Q j@2*x@+@ p@2*x@+@ - A# L j@1+:j! 5<) L
   "If a message is waiting (s not 0), print it, start a new line and clear s.";
   s@( s@$ L 0s! 0) L
   "b buy  s sell  f refuel  t travel  q quit: "$]

"B: buy. Ask for a good (G), then for a quantity (N, limited to 30), work out the cost t";
"   and check it. A bad good or a refusal leaves at once with the \ guard; a refusal also";
"   sets the message s for the next screen.";
[B "Buy which good (1-3)? "$ G j! j@0<\ L "How many? "$ N v! v@30>( 30v! 0) L
   "t = quantity x price here. Guard 1: more than we have in credits? The flag is copied";
   "(:) so that one copy runs the block which sets the message (the block ends with 0, so";
   "it drops out) and the other copy is the flag the backslash tests: if true, leave B.";
   v@j@2*k@+@* t!
   t@m@>:( "Not enough credits."s! 0)\
   "Guard 2: cargo now plus the new units above 30? The same copy and break idiom.";
   H v@+ 30>:( "Not enough room in the hold."s! 0)\
   "Pay, and add the units to cell j of the cargo.";
   m@t@-m! j@2*q@+@ v@+ j@2*q@+!]

"C: sell. The same questions as B. Guard: selling more than the cargo of that good?";
"   Then the credits grow by quantity x price here and the cargo shrinks.";
[C "Sell which good (1-3)? "$ G j! j@0<\ L "How many? "$ N v! L
   v@ j@2*q@+@ >:( "You don't have that many."s! 0)\
   m@ v@j@2*k@+@*+ m! j@2*q@+@ v@- j@2*q@+!]

"F: refuel at 5 credits a unit, as much as you can afford. t = room in the tank (20 - f),";
"   v = what the credits buy (m divided by 5). If v is less than t use v. Then add t to the";
"   fuel and pay 5 x t.";
[F 20f@-t! m@5/;v! v@t@<( v@t! 0) t@f@+f! m@t@5*-m! "Refuelled."s!]

"E: something may happen on the way. t is a random number 0 to 9, so each event has a";
"   chance of 1 in 10 and 7 in 10 nothing happens. 0: pirates halve each cargo cell";
"   (the quotient of a division by 2, so odd units round down). 1: a wreck gives 150";
"   credits. 2: engine trouble costs two days.";
[E 10R t!
   t@0=( "Pirates took half your cargo!"s! 0j! 1( j@2*q@+@ 2/; j@2*q@+! j@1+:j! 3<) 0)
   t@1=( "You salvaged a wreck: +150 credits."s! m@150+m! 0)
   t@2=( "Engine trouble: two days lost."s! d@2+d! 0)]

"T: travel. Ask for the planet 1-5 (not echoed). j = planet - 1. Leave at once if it is not";
"   a planet or it is the one we are on. t = distance = fuel needed. Then a guard on the";
"   fuel, burn it, add the days (distance divided by 3, plus 1), arrive: p = j, new";
"   prices (P) and a chance of an event (E).";
[T "To which planet (1-5)? "$ K 49- j! L j@0< j@4>| j@p@=|\
   j@2*x@+@ p@2*x@+@ - A t!
   t@f@>:( "Not enough fuel."s! 0)\
   f@t@-f! d@ t@3/;1+ + d! j@p! P E]

"Main program";
"";
"Start the random state at 0; K will stir it while it waits for the first key.";
0r!
"Names: the strings hold 5 names of 8 characters, and 3 good names of 8 (blank padded).";
"Their addresses go to u and g.";
"Sol     Vega    Rigel   Deneb   Altair  "u!
"Food    Ore     Tech    "g!
"Base prices of Food, Ore and Tech: 20, 60 and 200 credits (heap block e).";
6_e! 20e@! 60e@2+! 200e@4+!
"Blocks for the prices here (k) and the cargo (q, all empty).";
6_k! 6_q! 0q@! 0q@2+! 0q@4+!
"Planet positions on a line: Sol 0, Vega 3, Rigel 7, Deneb 12, Altair 18 (block x).";
10_x! 0x@! 3x@2+! 7x@4+! 12x@6+! 18x@8+!
"Start: 500 credits, 20 fuel, day 1, at planet 0, no message.";
500m! 20f! 1d! 0p! 0s!
"Title, wait for a key (the wait seeds r) and drop it; then set the first prices.";
"/{SPACE TRADER. Press a key to start."$ L K; P

"Main loop. Each turn: show the screen, read a key, echo it, and act on it with the";
"if blocks (98 b, 115 s, 102 f, 116 t). The loop goes on until the day is above 40 or the";
"key was q (113): the two flags are ORed and ~ negates them for the do-while.";
1( S K c! c@' L
   c@98=( B 0) c@115=( C 0) c@102=( F 0) c@116=( T 0)
   d@40> c@113=| ~)

"The end. Clear the screen and say on which day it was (/d).";
"/{GAME OVER on day /d"$ L L
"Sell the whole cargo at the prices here: add q x k for each good to the credits.";
0j! 1( j@2*q@+@ j@2*k@+@* m@+m! j@1+:j! 3<)
"Final credits (/m); then a profit message if above 500, or the other one if 500 or less.";
"Both tests are alternatives, so exactly one message is printed.";
"Your cargo sold for its value here. Final credits: /m"$ L
m@500>( "You made a profit of "$ m@500-# " credits."$ 0) m@501<( "You did not make a profit."$ 0) L
