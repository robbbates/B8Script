"MASTERMIND for B8Script. Break a code of four digits, each 1 to 6, in ten tries.";
"Black = right digit in the right place. White = right digit, wrong place.";
"Keys: type four digits 1 to 6 for each guess; y or n at the end of a game.";

"Variables";
"  s g  secret and guess, 4 bytes each   b e  black and white pegs";
"  t  try number   i k  counters   c  key";
"  p q n  used by C (and j, its counter)";
"  s and g are heap blocks: s holds the code, one digit value 1-6 per byte;";
"  g holds the current guess in the same form (values, not ASCII characters).";

"Routines";

"Random numbers come from 6`, (0 to 5). The interpreter stirs its seed while the";
"  game waits for a key (0?), so the code differs each game.";

"L: print a new line (CR LF), shorter than `' once used more than four times.";
[L`']

"C: ( addr digit -- n ).  How many times the digit appears in the 4 bytes at addr.";
"  p is the address, q the digit, n the count, j the position 0-3.";
"  The loop 1( ... 4<) runs four times: j`+ adds 1 to j and leaves it to compare.";
[C q!p! 0n! 0j!
   1( p@j@+,q@=( n`+; 0)    "if byte j equals the digit, count it";
      j`+ 4<)
   n@]

"A: ( -- ).  Read a guess of four keys 1 to 6 into g, echoing each one.";
"  0? waits for a key. A key counts only if its ASCII code is above 48 and below 55 (c@48> c@55<&);";
"  anything else is ignored and read again. Then c@' echoes the character,";
"  c@48- turns it into the value 1-6 and g@i@+. stores it as byte i of g.";
"  The loop goes on while i is below 4.";
[A 0i! 1( 0?c! c@48> c@55<&( c@' c@48- g@i@+. i`+; 0) i@4<)]

"P: ( -- ).  Score the guess: blacks go in b, whites in e.";
"  Blacks: compare s and g byte by byte (s@i@+, g@i@+, =) and count equals.";
"  Whites: for each value k from 1 to 6 the number of pegs matched in total is";
"  the smaller (`<) of (times k is in the secret) and (times k is in the guess). The";
"  sum of those minimums over all k counts every right digit, black or not.";
"  The whites are that total minus the blacks (e@b@-e!).";
[P 0b! 0i! 1( s@i@+, g@i@+, =( b`+; 0) i`+ 4<)
   0e! 1k! 1( s@k@C g@k@C `< e@+e! k`+ 7<)
   e@b@-e!]

"Main program";
"Get two 4-byte blocks for the code and the guess.";
4_s! 4_g!
"Clear the screen and print the title and rules (L is the new line word).";
`^ "MASTERMIND"$ L L
"I have picked four digits, each 1 to 6 (repeats allowed)."$ L
"You have ten tries. Press a key to start."$ L 0?; L

"Outer loop: one game per pass.  First choose the secret: 6`,1+ gives 1 to 6.";
1( 0i! 1( 6`,1+ s@i@+. i`+ 4<)
   "Inner loop: one try per pass, t is the try number, from 1.";
   "  Print the number, right-aligned (a space first if t is below 10), read the";
   "  guess (A), score it (P) and print the pegs. Go on while t, after the";
   "  increment, is still 10 or less (t`+ 11<) and not cracked (b below 4).";
   1t! 1( t@: 10<(" "$ 0) # ": "$ A P
          "   "$ b@# " black, "$ e@# " white"$ L
          t`+ 11< b@4<& )
   "After the loop: cracked, or out of tries (then reveal the code, digit + 48).";
   b@4=( "Cracked in "$ t@1-# " tries!"$ 0)
   b@4<( "Out of tries. The code was "$ 0i! 1( s@i@+,48+' i`+ 4<) 0)
   "Ask again: the key is echoed and compared with y (121). True repeats the game.";
   L L "Play again? (y//n) "$ 0?:' L L 121= )
"Bye."$ L
