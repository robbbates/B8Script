"ROBOTS for B8Script, after BSD robots. The robots step toward you every turn.";
"Two robots that meet leave a junk heap *, and a robot that walks into junk is";
"destroyed. Destroy every robot to reach the next wave, which has 10 more.";
"Keys: q w e a d z x c move (the 3 x 3 square of keys around s), s stays put,";
"space waits until the wave is over or a robot is next to you, t teleports";
"(to a random free cell: robots may be next to it), Q quits. 10 points a robot.";
"The field is 60 x 20, in a frame at the top left of an 80 x 24 screen.";
"";
"How a turn works. You move one step (or stay, or teleport); then every robot takes one step";
"toward you, in both directions at once, so it may move diagonally. A robot that steps onto";
"you catches you and the game is over. A robot that steps onto a junk heap is destroyed (10";
"points). If it steps onto a cell where another robot has just arrived, both are destroyed";
"(20 points) and a junk heap is left. You may not step onto junk, but you may step onto a";
"robot, which is fatal. When the last robot is gone a new wave starts, with 10 more robots";
"(never more than 40).";
"";

"Variables";
"  g  the field, 60 x 20 bytes, cell = y*60+x: 0 empty, 1 junk, 2+i robot i";
"  u  robot cells, 40 cells (-1 = destroyed)   n  robots this wave   k  robots left";
"  p  your cell   e f  your column and row   h  1 when you are caught   c  key";
"  s  score   w  wave   z  1 when the robots get a turn";
"  a b  a robot's cell and the cell it steps to   d o  step in x and y";
"  i j v  scratch   r  random state";
"";
"Data layout. A cell number is y x 60 + x, with x from 0 to 59 and y from 0 to 19. The field";
"g has one byte per cell. It holds 0, a 1 for junk, or 2 + i for robot i while that robot is";
"on the field. You are not in g: your cell is in p. The robots are numbered 0 to n-1; u is a";
"table of 2-byte cells, u + 2 x i holding the cell of robot i, or -1 once it is destroyed.";
"On the screen (rows and columns from 0 at the top left) the cell (x, y) is shown at";
"screen row y + 1 and column x + 1, inside a frame that takes row 0 and column 0, and";
"row 21 and column 61.";
"";

"Routines";

"M: n d -- n mod d.";
[M/%;]

"R: n -- random 0 to n-1: r = r x 75 + 74 (a linear congruential generator, wrapping at 16";
"   bits), then its high byte (r divided by 256, AND 255) taken modulo n.";
[R r@75*74+:r! 256/;255& %M]
"   Exactly: for a state of 0 to 32767 this is its high byte. Above that the state reads as";
"   negative and the division rounds toward zero, so the byte comes out one more than the";
"   high byte (255 turning into 0) unless the low byte is 0. It is still a number 0 to 255.";

"K: -- key. Wait for a key; while waiting r is stirred, so that the time the player takes to";
"   press a key seeds the random numbers.";
[K0 1(;r@1+r!1?:0=)]

"L: new line.";
[L13'10']

"A: n -- absolute value. If n is negative (:0< tests a copy), multiply it by -1.";
[A:0<(-1*0)]

"Screen. The strings do most of it: /{ clears the screen and homes the cursor, /}";
"   clears to the end of the line, and /~ moves the cursor to the row and column under";
"   the string's address (several /~ take a pair each, the pair pushed last first).";
"   Y: row column -- move the cursor. Rows and columns count from 0.";
[Y"/~"$]

"N: n -- its sign: 1, 0 or -1. The first block turns a positive n into 1 (drops n, pushes 1,";
"   the 0 closes the block); the second turns a negative n into -1. Zero is left as it is.";
[N:0>(;1 0):0<(;-1 0)]

"Q: i -- the address of robot i's cell: u + 2 x i (the doubling, :+, is faster than 2*).";
[Q:+u@+]

"P: cell -- move the cursor to that cell (the frame is at row 0, column 0).";
"   60 is added first, so the division by 60 gives the row y + 1 and the column x (the";
"   remainder, on top), and 1 is added to the column. So row = y + 1, column = x + 1.";
[P60+60/1+Y]

"V: cell -- draw what the field holds there. The cursor goes to the cell (P, using a copy),";
"   the field byte is read; a robot (2 or more) is turned into 2; the byte then picks a";
"   character from the string space, star, plus: empty, junk, robot.";
[V:P g@+, :1>(;2 0) " *+"+,']

"Z: draw you, and leave the cursor on you. The cursor goes to p, the character @ (64) is";
"   printed, and the cursor goes back to p, because printing moves it on one place.";
[Z p@P 64' p@P]

"S: the score, the wave and the robots left (/s /w /k), in the column at the right of";
"   the frame, rows 1 to 3. /} clears the rest of each line.";
[S 3 64 2 64 1 64"/~Score  /s/}/~Wave   /w/}/~Robots /k/}"$]

"H: clear the screen (/{), draw the frame and the keys.";
"   The top edge is a +, 60 minus signs and a +. The count 60 is on the stack: each pass";
"   of the do-while prints one minus, subtracts 1 and repeats while the count is not 0.";
"   The side bars, | at column 0 and column 61, are drawn for the rows j = 1 to 20 (one";
"   string with two /~). The bottom edge is on row 21, as the top one. Last the key";
"   help, rows 6 to 13 from column 64, in one string: the pairs are pushed last row first.";
[H "/{+"$ 60 1( "-"$ 1-: ); "+"$
   1j! 1( j@61 j@0"/~|/~|"$ j@1+:j! 21<)
   21 0Y "+"$ 60 1( "-"$ 1-: ); "+"$
   13 64 12 64 11 64 10 64 8 64 7 64 6 64
   "/~q w e/~a s d  move/~z x c/~s      stay/~space  wait/~t      teleport/~Q      quit"$]

"F: -- cell  a random free cell that isn't yours.";
"   A 0 is pushed, and the loop drops it at once (it only gives the loop something to drop).";
"   A cell is made: random row 0 to 19, times 60, plus a random column 0 to 59. A copy is used";
"   to read the field byte; over ({:}%) copies the cell again to compare it with p. The OR of";
"   the byte and the comparison is not 0 if the cell is occupied or is yours, and then the";
"   loop tries again. The new cell is left on the stack at the end.";
[F 0 1( ; 20R60* 60R+ :g@+, {:}%p@=| )]

"W: a new wave: clear the field, place you and the robots, draw it all.";
"   The wave number goes up by one, and n, the number of robots, is 10 x w, but at most 40";
"   (:40> tests a copy: if above 40 the block drops it and pushes 40). k, the robots left,";
"   starts as n.";
[W w@1+:w! 10* :40>(;40 0) :n! k!
   "Clear the field: an address, starting at g, steps by 2 and stores a 0 cell each time,";
   "while it is below the end of the field (g + 1200). :0%! is: copy, 0, swap, store.";
   g@ 1( :0%! 2+ :g@1200+<) ;
   "You: p is set to -1 first, so that F can't reject any cell for being yours. Then F gives";
   "a free cell and it becomes p.";
   -1p! F p!
   "Robots: for each i from 0 to n-1, find a free cell (F), keep a copy in robot i's cell,";
   "and put 2 + i in the field at that cell. The swap puts the address above the byte.";
   0i! 1( F :i@Q! i@2+ %g@+. i@1+:i! n@<)
   "Draw: the frame and keys (H), then every robot, then the score and you.";
   H 0i! 1( i@Q@V i@1+:i! n@<) S Z]

"O: take every robot off the field and the screen: for each robot i that is not destroyed";
"   (its cell above -1) zero its field byte, put the cursor on the cell and print a space.";
"   The robots are put back, one by one, as they move.";
[O 0i! 1( i@Q@:a! -1>( 0a@g@+. a@P 32' 0) i@1+:i! n@<)]

"T: robot i steps toward you: into junk it is destroyed; onto another robot both";
"   are, and leave junk";
"   a is its cell, and if that is negative the robot is gone: leave at once (the backslash).";
"   The step: the cell a is divided by 60 for its row and column. The difference of your";
"   column e and its column, and then of your row f and its row, goes through N (the sign:";
"   -1, 0 or 1). So the step is dx + 60 x dy and the new cell b = a + the step. The field";
"   byte at b is v. After this, the cases (the field was cleared by O, so it holds only";
"   robots that have already moved this turn, and junk):";
"   v = 0, the cell is free: the robot moves there (field byte 2 + i, cell updated).";
"   v = 1, junk: the robot is destroyed (cell -1), robots left k - 1, score + 10.";
"   v above 1, another robot, number v - 2: it and this robot are destroyed, a junk heap 1 is";
"   put at b and drawn (star, 42), robots left k - 2, score + 20.";
"   Last: if b is your cell, you are caught (h = 1). The cases test v, not the field, so";
"   one run of T does only the case that fits.";
[T i@Q@:a! 0<\
   a@60/ e@%-N % f@%-N 60*+ a@+:b! g@+,:v!
   0=( i@2+b@g@+. b@i@Q! 0)
   v@1=( -1i@Q! k@1-k! s@10+s! 0)
   v@1>( -1v@2-Q! -1i@Q! 1b@g@+. b@P 42' k@2-k! s@20+s! 0)
   b@p@=( 1h! 0)]

"D: draw every robot left. For each robot i, its cell is read; if it is not -1 the cell is";
"   copied, V draws it, and the cell is dropped. The block leaves the cell either way.";
[D 0i! 1( i@Q@ :-1>( :V 0); i@1+:i! n@<)]

"X: the robots' turn. O takes the robots off, T moves them all one by one (in order of i),";
"   D draws those left, S shows the score, and you are drawn again unless you were caught.";
[X O 0i! 1( T i@1+:i! n@<) D S h@0=( Z 0)]

"J: -- flag  is a robot next to you? j collects the answer, starting at 0. For every robot";
"   that is not destroyed: the cell is divided by 60, giving its row and column. The column";
"   difference from e is made positive (A) and tested to be below 2; the swap brings the row";
"   to the top for the same test against f. Both must be true (&), and the result is ORed";
"   into j. Next to you also counts a robot on your own cell, but that ends the game.";
[J 0j! 0i! 1( i@Q@:a! -1>( a@60/ e@-A2< %f@-A2<& j@|j! 0) i@1+:i! n@<) j@]

"U: a move key in c: step there, unless it is off the field or onto junk";
"   (onto a robot is allowed, and fatal). Sets z when the robots get a turn";
"   The keys q w e, a s d and z x c are laid out as the 3 x 3 square of a keypad. First";
"   v = 1 + the position of the key c in the string (0 if it is not a move key, and then";
"   the backslash leaves). Position 0 to 8 is split by 3 into a row (quotient) and a column";
"   (remainder); subtracting 1 from each gives the step: d = dx and o = dy, -1 to 1.";
"   The next lines check the new column e + d is from 0 to 59 and the new row f + o from 0";
"   to 19 (each test copies the value, tests it is above -1, swaps and tests it is below the";
"   limit; the two results are ANDed together); if not, leave. Then the new cell b = p + d";
"   + 60 x o; leave if it holds junk. Last the move: erase you at the old cell, p = b, z = 1,";
"   and if a robot is there (v above 1), you are caught.";
[U 0v! 0j! 1( "qweasdzxc"j@+, c@=( j@1+v! 0) j@1+:j! 9<)
   v@0=\ v@1- 3/ 1-d! 1-o!
   e@d@+ :-1> %60<& f@o@+ :-1> %20<& & 0=\
   p@d@+ o@60*+ :b! g@+,:v! 1=\
   p@P 32' b@p! 1z! v@1>( 1h! 0)]

"Main program";
"";
"Allocate the field (1200 bytes) and the robot table (80 bytes), and start the random";
"state at 0 (the first key wait stirs it). Then the title and the rules.";
1200_g! 80_u! 0r!
"/{ROBOTS"$ L L "Robots chase you. When two run into each other they leave a junk heap,"$ L
"and a robot that walks into junk is destroyed. Destroy them all to reach the"$ L
"next wave. q w e a d z x c move, s stays, space waits, t teleports, Q quits."$ L L
"Press a key."$ K;
"Game loop: one pass per game. Score 0, wave 0, not caught, then W starts wave 1.";
"Turn loop: wait for a key (c). z = 0, no robot turn yet. The column and row of p";
"are found by dividing it by 60 (e gets the remainder, f the quotient).";
"t: erase you, move to a random free cell (F), the robots get a turn (z = 1).";
"space: only if no robot is next to you (J), repeat the robots' turn (X) while there are";
"robots left, you are not caught and none is next to you.";
"A move key: U moves you and sets z. If z, the robots move (X). If every robot is gone";
"and you are alive, the next wave (W). The turn loop ends when you are caught or the key";
"was Q (81).";
1( 0s! 0w! 0h! W
   1( 0? c! 0z! p@60/e!f!
      c@116=( p@P 32' F p! 1z! 0)
      c@32=( J0=( 1( X k@0> h@0=& J0=& ) 0) 0)
      U z@( X 0)
      k@0= h@0=&( W 0)
   h@0= c@81=0=&)
   "Game over: on row 22 (AARRrrgghhhh if you were caught), the score and wave, and the";
   "question. /} clears the rest of the line. The loop repeats if the key is y (121).";
   22 0Y h@( "AARRrrgghhhh....  "$ 0) "Score /s, wave /w. Play again? (y//n) /}"$
   K 121=)
23 0Y "Bye."$ L
