"SIMON for B8Script. A string of digits flashes and is wiped; type it back.";
"Each round adds one digit. One mistake ends the game, and the score is the number of";
"  rounds you got right. The digits are 1 to 8. This needs a console that clears to the";
"  end of a line (the //} escape).";
"Keys: any key to start; then the digits. A key during the flash ends it early.";
"Nothing is stored: the digits are the output of a generator that is reset to the";
"  same seed, so they replay once to show them and again to check your answer.";
"Variables: r the generator's state, s its seed, n the length of the string now.";

"D ( -- c ): the next digit's character. r = r * 75 + 74, kept (the : and r! store a";
"  copy). 256//; keeps the high byte, 7& keeps its three low bits and 49+ makes a";
"  character from 1 to 8. The low bit of r never changes, so the high byte is used.";
[D r@75* 74+ :r! 256/ ; 7& 49+]

"Start: print the title, count up until a key comes (the key is used up by 0=) and";
"  keep the count as the seed s. The length n starts at 1.";
"SIMON key"$
0 1( 1+ 1? 0= ) s!
1n!

"Main loop: one round per pass, which goes on while the answer is right.";
"  Show: a new line, reset r to s, and print n digits. The count n is on the stack:";
"  D prints a digit, 1- counts down, and : keeps a copy as the flag. Then 999? waits one second";
"  (or a key, which is dropped), and //M//} goes to the start of the line and clears it.";
"  Check: reset r to s again. The flag starts as -1 (all ones). For each of n digits:";
"  read a key (echoed), compare it with the next D, and AND the result into the flag.";
"  A wrong digit does not stop the typing: the round just fails at the end.";
"  The flag is kept to the end of the round: if it is true, n goes up by 1 (the :(";
"  keeps a copy), and it is also the loop's flag.";
1( "/M/J"$
   s@ r!
   n@ 1( D ' 1- : ) ;
   999? ;
   "/M/}"$
   s@ r!
   -1 n@ 1( % 0? :' D = & % 1- : ) ;
   :( n@1+ n! 0))

"The end: n counts the round that failed, so the score is n - 1.";
" score "$
n@1- #
