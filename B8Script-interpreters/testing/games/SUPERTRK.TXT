"SUPER STAR TREK for B8Script. A galaxy of 8 x 8 quadrants, each 8 x 8 sectors.";
"Destroy every Klingon before the stardates run out. Dock next to a starbase B to refuel.";
"Keys: m move, j warp, l long-range scan, g galaxy map, p phasers, t torpedo,";
"z shields, h help, q quit. Courses and amounts are typed as numbers, then Enter.";

"How it works, in short: the galaxy is a table of 64 numbers, one per quadrant,";
"telling how many Klingons, starbases and stars it holds. You are always inside";
"one quadrant, and only that quadrant exists in detail: when you enter one, E";
"builds its 8 x 8 sectors in a byte table from the galaxy number and places the";
"ship, Klingons, bases and stars at random empty sectors. Leaving it throws the";
"sectors away (killed Klingons are removed from the galaxy table, so a quadrant";
"is rebuilt without them). The main loop is: show the scan (S), dock if next to a";
"base (W), read a command, run it, let the Klingons fire (F), check the end.";

"Variables";
"  g  galaxy: 64 cells, each Klingons*100 + bases*10 + stars";
"  o  your record of the galaxy: value + 1, or 0 where you haven't scanned";
"  s  sectors of this quadrant (64 bytes): 0 empty 1 star 2 Klingon 3 base 4 you";
"  w  Klingon energy by sector (64 cells)";
"  u v  quadrant (0-7)   x y  your sector (0-7)   e  energy   h  shields";
"  t  torpedoes   d  stardates left   c  Klingons left in the galaxy";
"  p q  course step in x and y   a b  target sector   n  number typed";
"  f i j k z  scratch   m  message flag   r  random state";
"  (m is not used by this version.)";

"Data layout. g and o are tables of 64 cells (128 bytes); the cell of quadrant";
"(u, v) is at g + 2*(v*8 + u), and the same for o. A g value is read as three";
"digits: 213 means 2 Klingons, 1 base, 3 stars. An o value is the g value + 1 (so";
"0 can mean never scanned): the long-range scan and G subtract 1 again to print.";
"s is a table of 64 bytes, one per sector: the cell of sector (x, y) is at";
"s + y*8 + x, and word C computes it. w is a table of 64 cells (128 bytes) with";
"the same index, 2 bytes per sector: w + 2*(y*8 + x) holds the energy of the";
"Klingon at that sector (200 to 299 when it is made).";
"Courses: 1 east, 2 north-east, 3 north, 4 north-west, 5 west, 6 south-west,";
"7 south, 8 south-east. North is towards smaller y, as the scan prints y downwards.";

"Routines";

"M: ( n d -- n mod d ).  Division leaves quotient and remainder (remainder on top);";
"  % swaps them and ; drops the quotient. Used by R and others.";
[M/%;]

"R: ( n -- 0..n-1 ).  A random number. r is a linear congruential generator:";
"  r = r * 75 + 74 (16-bit wrap); the : keeps a copy of the new r and r! stores";
"  the other. Dividing by 256 (and dropping the remainder) keeps r div 256, about";
"  the top byte, the best bits; 255& cuts it to 0-255. Then % brings n on top";
"  and M takes that byte mod n.";
[R r@75*74+:r! 256/;255& %M]

"K: ( -- key ).  Wait for a key, stirring r while waiting, so the random numbers";
"  differ from game to game. The 0 is a dummy that the first pass drops. Each";
"  pass: drop the old value, add 1 to r, then 1? looks for a key (the key, or 0";
"  at once). : 0= makes a flag, true while no key came, which repeats the loop.";
"  The key stays on the stack when the loop ends.";
[K0 1(;r@1+r!1?:0=)]

"L: ( -- ).  New line: CR (13) then LF (10).";
[L13'10']

"A: ( n -- |n| ).  Absolute value: copy, test for negative, and if so negate";
"  with -1*.";
[A:0<( -1* 0)]

"N: ( -- n )  read a number, ending with Enter. n is built up digit by digit.";
"  A key z counts if it is above 47 and below 58 (a digit); then it is echoed";
"  with ' and n = n*10 + (z - 48). Other keys are ignored. The loop ends on";
"  Enter (13). L then starts a new line and n is left on the stack.";
[N 0n! 1( K z! z@47> z@58<&( z@' n@10*z@48-+n! 0) z@13= ~) L n@]

"C: ( x y -- address )  the address of sector (x, y) in table s: s + y*8 + x.";
[C8*+s@+]

"I: ( -- flag )  is the target a,b inside the quadrant? Both a and b must be";
"  below 8 and above -1 (that is, 0 to 7). The four tests are joined with &.";
[I a@8<a@-1>& b@8<& b@-1>&]

"D: ( -- flag )  ask for a course 1-8 and set the step p,q; false if not a course.";
"  Used by move, warp and torpedo, which end at once if it gives false.";
[D "Course (1-8, 1 = east, 3 = north)? "$ K :' L 48- z!
   "The key minus 48 is the course z. z@0> z@9<& is true for 1 to 8. The : ( copies";
   "that flag, which is left as the result. In the body each string is a table of";
   "eight digits, one per course. z@1-+ is the address of the entry (the string";
   "address plus z - 1), , fetches that character and 49- turns the digit into the";
   "number it stands for, minus 1: the digits 0 1 2 stand for steps -1, 0, +1.";
   "The first string gives the step p in x, the second the step q in y.";
   z@0> z@9<&:( "22100012" z@1-+, 49- p!  "10001222" z@1-+, 49- q! 0)]

"P: ( v -- )  put value v in a random empty sector of this quadrant; a is left";
"  holding that sector's address (not its coordinates).";
"  The loop picks a random x and y (8R each), turns them into an address with C,";
"  keeps it in a, and fetches the byte there: while it is not 0 (occupied) the";
"  loop repeats. Then v (kept in f) is stored at the empty sector.";
[P f! 1( 8R 8R C a! a@, ) f@a@.]

"E: ( -- )  enter quadrant u,v: build its sectors from the galaxy table.";
[E
   "First clear all 64 sector bytes to 0 (empty), counting i from 0 to 63.";
   0i! 1( 0s@i@+. i@1+:i! 64<)
   "k is the galaxy value of this quadrant. The record o gets that value + 1 (so a";
   "scanned quadrant is never 0 there). The cell number is v*8 + u, times 2 bytes.";
   v@8*u@+2*g@+@ :1+ v@8*u@+2*o@+!  k!
   "The ship (value 4) goes to a random sector. P leaves its address in a, so";
   "a - s is the sector number: its remainder when divided by 8 is x and its";
   "quotient is y.";
   4P a@s@- :8M x! 8/; y!
   "Klingons: k div 100 of them. Each pass of the loop, if the count is not 0, puts";
   "a Klingon (2) and sets its energy 200 + 0 to 99 in table w at 2*(sector number).";
   "The count is lowered and copied; the loop goes on while it is above 0. This";
   "shape (:( body 0) 1-: 0>) runs the body n times, and zero times for n = 0.";
   k@100/; 1( :( 2P 200 100R+ a@s@- 2*w@+! 0) 1-: 0>) ;
   "Bases: the tens digit, (k div 10) mod 10. Then stars: the units digit, k mod 10.";
   k@10/;10M 1( :( 3P 0) 1-: 0>) ;
   k@10M 1( :( 1P 0) 1-: 0>) ;]

"Q: ( -- n )  the number of Klingons in this quadrant: the hundreds digit of the";
"  galaxy value (the table is the truth; the sectors on screen are drawn from it).";
[Q v@8*u@+2*g@+@ 100/;]

"Y: ( -- )  change this quadrant's Klingon count by n (n is -1 when one is killed).";
[Y
   "The galaxy cell address is made once and copied: fetch its value, add n*100 and";
   "store it back (% puts the address on top for !). Then the total in c is changed";
   "too, and the record o is brought up to date with the new value + 1.";
   v@8*u@+2*g@+ :@ n@100* + %! c@n@+c! v@8*u@+2*g@+@1+ v@8*u@+2*o@+!]

"S: ( -- )  short-range scan with the status beside it: 8 rows, one line each.";
"  Each row j prints a space and a character for each of the 8 sectors, then five";
"  spaces and one status line, chosen by the row number.";
[S L 0j! 1(
     "Sectors: the value of sector (i, j) is added to the address of .*KBE, so the";
     "character is empty, star, Klingon, base or Enterprise. , fetches it, ' prints.";
     0i! 1( 32' i@j@C, ".*KBE"+,' i@1+:i! 8<) "     "$
     "The status text by row: 0 stardates, 1 quadrant, 2 sector (both shown from 1),";
     "3 energy, 4 shields, 5 torpedoes, 6 Klingons left. Row 7 is the condition: RED";
     "when there are Klingons in this quadrant (Q not 0), else GREEN (the 0= test).";
     j@0=( "Stardates  "$ d@# 0) j@1=( "Quadrant   "$ u@1+# ","$ v@1+# 0)
     j@2=( "Sector     "$ x@1+# ","$ y@1+# 0) j@3=( "Energy     "$ e@# 0)
     j@4=( "Shields    "$ h@# 0) j@5=( "Torpedoes  "$ t@# 0)
     j@6=( "Klingons   "$ c@# 0) j@7=( "Condition  "$ Q( "RED"$ 0) Q0=( "GREEN"$ 0) 0)
     L j@1+:j! 8<)]

"O: ( -- )  long-range scan of the 3 x 3 quadrants around you. For each one inside";
"  the galaxy, print its three digits (Klingons, bases, stars) and record them in o.";
"  Outside the galaxy it prints dashes. j and i run from -1 to 1.";
[O L -1j! 1( -1i! 1(
        "A space, then the quadrant a,b = (u + i, v + j). The long test is the same as";
        "word I but on quadrants: 0 to 7 in both. The : copies the flag for the first";
        "block; the flag left over is turned round by 0= and so selects the dashes";
        "for a quadrant outside the galaxy.";
        32' u@i@+ a! v@j@+ b! a@8< a@-1>& b@8<& b@-1>&
        "Inside: fetch the galaxy value, store its value + 1 in the record o, and";
        "print it as three digits with U (U takes the value that was left).";
        :( b@8*a@+2*g@+@ :1+ b@8*a@+2*o@+! U 0) 0=( "---"$ 0)
     i@1+:i! 2<) L j@1+:j! 2<)]

"U: ( n -- )  print n as exactly three decimal digits (n is below 1000).";
"  Each digit is the quotient or remainder by 100, 10 and 1, plus 48 (the ASCII";
"  code of 0), printed with '. : copies n; dividing by 100 gives quotient and remainder and";
"  ; drops the remainder; 10M takes a remainder directly.";
[U :100/;48+' :10/;10M48+' 10M48+']

"G: ( -- )  the galactic record: your table o as an 8 x 8 map. Scanned quadrants";
"  show their three digits (the stored value - 1), the others show dots.";
[G L "   1   2   3   4   5   6   7   8"$ L
   "Row j: print its number (from 1), then for each column i look at the record";
   "o at cell j*8 + i. The : copies it: non-zero means scanned, so print a space";
   "and the three digits (:1-U subtracts the 1 again); else print dots.";
   0j! 1( j@1+# 0i! 1(
     j@8*i@+2*o@+@ :( 32' :1-U 0) 0=( " ..."$ 0) i@1+:i! 8<) L j@1+:j! 8<)]

"W: ( -- )  dock if a base is next to you: look at the 3 x 3 sectors around the ship.";
"  f is the found flag; i and j run from x-1 to x+1 and y-1 to y+1, a,b hold the";
"  sector being looked at so that I can test it. If it is inside and holds a base";
"  (3), f is set. After the search, if f: energy 3000, torpedoes 10, shields 0.";
[W 0f! y@1-j! 1( x@1-i! 1( i@a! j@b! I( i@j@C,3=( 1f! 0) 0) i@1+:i! x@2+<) j@1+:j! y@2+<)
   f@( 3000e! 10t! 0h! "Docked: energy and torpedoes restored."$ L 0)]

"V: ( -- )  impulse: move up to 7 sectors along a course. First ask for the course";
"  (D sets p,q; if it is not a course, D gives false and the ~ guard exit ends V),";
"  then the number of sectors k.";
[V D ~\ "Sectors (1-7)? "$ N k!
   "a,b is the sector being moved to, starting from you. Each pass: step by p,q.";
   "If outside the quadrant, stop. If the sector is not empty, stop (blocked).";
   "Otherwise clear your old sector, move x,y, draw 4 there, and the move costs 10";
   "energy. k counts down; the loop goes on while k is above 0. Note that it always";
   "moves at least once, since the test comes at the end.";
   x@a! y@b! 1( a@p@+a! b@q@+b!
      I0=:( "You stop at the edge; warp to leave the quadrant."$ L 0)\
      a@b@C,0=~:( "Blocked."$ L 0)\
      0x@y@C. a@x! b@y! 4x@y@C. e@10-e! k@1-:k! 0>)]

"J: ( -- )  warp to another quadrant: u,v change by the course step times the factor.";
[J D ~\ "Warp factor (1-7)? "$ N k!
   "The target is a = u + p*k and b = v + q*k (b! then a! takes them off in order).";
   "If it leaves the galaxy (below 0 or above 7), stop; the : copies the flag.";
   u@p@k@*+ v@q@k@*+ b! a!
   a@0< a@7>| b@0<| b@7>|:( "That leaves the galaxy."$ L 0)\
   "Go: the new quadrant is a,b; it costs 100 energy per factor and 1 stardate,";
   "and E builds it. (Energy is not checked: too little means game over.)";
   a@u! b@v! e@k@100*-e! d@1-d! L "Warp drive engaged."$ L E]

"H: ( -- )  phasers: energy split among the Klingons here, weaker with distance.";
"  k is the energy you give; each Klingon is hit for k div Q times 3, divided by";
"  its distance plus 2 (the distance is |dx| + |dy|, A being the absolute value).";
[H Q0=:( "No Klingons here."$ L 0)\ "Phaser energy? "$ N k!
   k@e@>:( "Not enough energy."$ L 0)\ e@k@-e!
   "Loop over every sector (i across, j down) holding a Klingon (2).";
   0j! 1( 0i! 1( i@j@C,2=(
        "f is the damage: k div Q (the Klingons still alive, since Q is read again";
        "each time) times 3, divided by (|dx| + |dy| + 2).";
        k@Q/;3* i@x@-A j@y@-A + 2+ /; f!
        "Take f off its energy: the address of its cell in w is made, the old energy";
        "fetched and f subtracted; the new value is stored with :{ %! } (kept on the";
        "return stack across the store, then brought back). Dead if below 1.";
        i@j@C s@- 2*w@+ :@ f@- :{ %! }
        "Destroyed: say so, clear the sector, and Y lowers the galaxy count by one.";
        "Otherwise: report the hit. The ~ block runs when the flag is false.";
        1<:( "Klingon at "$ i@1+# ","$ j@1+# " destroyed!"$ L 0i@j@C. -1n! Y 0)~(
             "Klingon at "$ i@1+# ","$ j@1+# " hit for "$ f@# "."$ L 0) 0)
      i@1+:i! 8<) j@1+:j! 8<)]

"T: ( -- )  photon torpedo. It starts at your sector and moves one sector at a time";
"  along the course until it leaves the quadrant or hits something.";
[T t@1<:( "No torpedoes left."$ L 0)\ D ~\ t@1-t!
   "a,b is the torpedo. Each pass: step, f = 0 and, if inside (I), f = what is";
   "there. If outside the ~ block says it missed. Then by f: 2 Klingon (destroyed,";
   "sector cleared, Y lowers the count), 1 star (absorbed), 3 starbase (destroyed;";
   "only the sector is cleared, the galaxy table is not changed). The loop goes on";
   "while the torpedo is still inside and f is 0 (empty).";
   x@a! y@b! 1( a@p@+a! b@q@+b! 0f!
      I:( a@b@C,f! 0)~( "Torpedo missed."$ L 0)
      f@2=( "Klingon destroyed!"$ L 0a@b@C. -1n! Y 0)
      f@1=( "A star absorbs the torpedo."$ L 0)
      f@3=( "You destroyed a starbase!"$ L 0a@b@C. 0)
   I f@0=&)]

"Z: ( -- )  shields: move energy between the engines and the shields.";
"  k is the new shield level. The total e + h must cover it (the : copies the";
"  flag for the ( block, and the guard exit stops). Then the engines get what is";
"  left of the total, and the shields get k.";
[Z "Shield energy? "$ N k! k@e@h@+>:( "Not enough energy."$ L 0)\ e@h@+k@-e! k@h!]

"F: ( -- )  every Klingon here fires; the shields take it first.";
"  The damage is its energy divided by (distance + 2).";
[F 0j! 1( 0i! 1( i@j@C,2=(
        "f is the damage: the Klingon's energy from w, divided by |dx| + |dy| + 2.";
        i@j@C s@- 2*w@+@ i@x@-A j@y@-A + 2+ /; f!
        "Report the shot. If the shields h are less than f, the rest of f comes off";
        "the energy e and the shields drop to 0; otherwise just h = h - f.";
        "Klingon at "$ i@1+# ","$ j@1+# " fires: "$ f@# " units."$ L
        h@f@<:( f@h@- e@%-e! 0h! 0)~( h@f@-h! 0) 0)
      i@1+:i! 8<) j@1+:j! 8<)]

"X: help: print the list of commands (it does not use any variable).";
[X L "m  move: course 1-8 (1 east, 3 north, 5 west, 7 south), then 1-7 sectors."$ L
   "   Costs 10 energy a sector. Stars and bases block you."$ L
   "j  warp: course, then warp factor 1-7 quadrants. 100 energy each; 1 stardate."$ L
   "l  long-range scan of the 3 x 3 quadrants around you. Each number is"$ L
   "   Klingons, bases, stars: 103 = 1 Klingon, no base, 3 stars."$ L
   "g  galaxy map of every quadrant you have scanned."$ L
   "p  phasers: the energy you give is shared among the Klingons here,"$ L
   "   and does less damage with distance."$ L
   "t  photon torpedo along a course; it destroys the first Klingon it hits."$ L
   "z  shields: set how much energy goes to the shields. They take hits first."$ L
   "Dock by moving next to a base B: energy, torpedoes and shields are restored."$ L
   "Klingons fire after you move, fire phasers or torpedoes in their quadrant."$ L]

"Main program";
"Allocate the tables: g and o 128 bytes each (64 cells), s 64 bytes, w 128 bytes.";
"Each _ returns the address of its new block, kept with !. Then the random state";
"is seeded with 0 (K stirs it) and the Klingons-left total is cleared.";
128_g! 128_o! 64_s! 128_w!
0r! 0c!
"The title and instructions. K waits for a key (so r is stirred); ; drops it.";
"/[[2J/[[H"$ "SUPER STAR TREK"$ L L
"Destroy every Klingon in the galaxy before the stardates run out."$ L
"Dock next to a starbase (B) to refuel."$ L L
"Commands: m move, j warp, l long-range scan, g galaxy map,"$ L
"          p phasers, t torpedo, z shields, q quit."$ L L "Press any key to begin."$ L K;

"Build the galaxy: a few Klingons, a base now and then, 1-8 stars everywhere";
"For each of the 64 quadrants (i):";
"  k is a random number 0 to 99. The Klingon count starts at 0 and is replaced by 1";
"  if k is above 82, by 2 if above 92 and by 3 if above 97 (the ; drops the old";
"  count). It is added to the total c; the : keeps a copy; 100* gives the hundreds.";
"  Then 100R90> is true 9 times in 100: a base adds 10. 8R1+ is 1 to 8 stars. The";
"  sum is stored in g at cell i; the record o at cell i is cleared (not scanned).";
0i! 1( 100R k! 0 k@82>( ; 1 0) k@92>( ; 2 0) k@97>( ; 3 0) :c@+c! 100*
       100R90>( 10+ 0) 8R1++ i@2*g@+! 0i@2*o@+! i@1+:i! 64<)
"Make sure there is at least one base: add one (10) to a random quadrant. The";
"address is made once and copied: fetch, add, then % and ! store it back.";
64R2*g@+ :@ 10+ %!
"If no Klingons were made at all, add 2 (200) to a random quadrant and set c = 2.";
c@0=( 64R2*g@+ :@ 200+ %! 2c! 0)

"Start in a random quadrant (u, v) and build it with E. Energy 3000, shields 0,";
"10 torpedoes, and stardates: 30 plus one per Klingon.";
8R u! 8R v! E
3000e! 0h! 10t! 30 c@+ d!
"Each turn: the command list, the scan and your status, then your command.";
"After a command runs, its results stay on screen until you press a key.";
"The loop: clear the screen, print the command line, scan (S) and dock if next";
"to a base (W), read a key into z, and run its command: m 109 move, j 106 warp,";
"l 108 long scan, g 103 galaxy map, p 112 phasers, t 116 torpedo, z 122 shields,";
"h 104 help, q 113 quit (sets the stardates to 0, which ends the loop).";
1( "/[[2J/[[H"$ "m move  j warp  l scan  g map  p phasers  t torpedo  z shields  h help  q quit"$ L
   S W
   "Command? "$ K :' L z!
   z@109=( V 0) z@106=( J 0) z@108=( O 0) z@103=( G 0)
   z@112=( H 0) z@116=( T 0) z@122=( Z 0) z@104=( X 0)
   z@113=( 0d! 0)
   "The Klingons here (Q not 0) fire after a move, phasers or torpedo, not warp";
   "(the test that z is not 106 is an extra safeguard). The flags are combined with &.";
   Q z@109= z@112=| z@116=| z@106=~ &&( F 0)
   "Unless you quit, wait for a key so that you can read the results.";
   z@113= ~( L "(press a key)"$ K; 0)
   "The loop goes on while Klingons remain (c at least 1), energy is at least 1";
   "and stardates are left (d at least 1). Each of the three < tests is true for a";
   "problem; | joins them and ~ turns the result round: true means carry on.";
   c@1< e@1<| d@1<| ~)

"The end: clear the screen, show the scan one last time and say how it ended.";
"No Klingons left: a win. Otherwise out of energy, or (quitting or out of time) a loss.";
"/[[2J/[[H"$ S L
c@1<( "Every Klingon is destroyed. The Federation is saved!"$ 0)
c@0>( e@1<( "The Enterprise has run out of energy."$ 0)
   e@0>( "Time is up. The Klingons win."$ 0) 0) L
