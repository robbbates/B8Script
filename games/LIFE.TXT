"Conway's Life on a 32 x 16 grid. Any key stops it.";
"Each grid has a border of dead cells (34 x 18 bytes), so the eight";
"neighbours of a cell are always at fixed offsets from its address.";
"The rules: a live cell with 2 or 3 live neighbours lives on; a dead cell with";
"exactly 3 live neighbours is born; every other cell is dead in the next generation.";
"It stops at a key press, or after 200 generations.";

"Hide the cursor while it runs: delete the next line for a terminal without ESC [?25l.";
"/[[?25l"$

"Variables";
"  g h  addresses of the current and next grids (one byte per cell, 0 or 1)";
"  a    address of the cell being worked on, in grid g";
"  j    row being worked on (1 to 16)";
"  k    generation number";

"Layout of a grid: 18 rows of 34 bytes, row after row. Column 0 and 33, and row 0";
"  and 17, are the border and always 0. The cell at column x (1-32) and row y (1-16)";
"  is the byte at grid + y * 34 + x. The eight neighbours are therefore at the";
"  offsets -35 -34 -33 (row above), -1 +1 (same row) and +33 +34 +35 (row below).";

"Routines";

"S: ( x y -- )  make that cell alive (x 1-32, y 1-16).";
"  34* turns y into a row offset, + adds x, g@+ gives the address. Then 1 % . stores";
"  the byte 1 at it (the 1 goes under the address by %, because . wants the byte";
"  first and the address on top).";
[S 34*+g@+ 1%.]

"N: ( -- n )  the number of live neighbours of the cell at a.";
"  Each a@35-, style group fetches the byte at a with an offset; the + adds it to";
"  what is on the stack. The first fetch starts the sum, the others add to it.";
"  Cells are 0 or 1, so the sum is the count.";
[N a@35-,  a@34-,+  a@33-,+
   a@1-,+           a@1+,+
   a@33+,+  a@34+,+  a@35+,+]

"R: ( -- )  point a just before the first cell of row j, that is at g + j * 34.";
"  The loops then step a one cell ahead before using it (a@1+:a!), so they";
"  start on column 1 of the row.";
[R j@34*g@+a!]

"P: ( -- )  print grid g at the top of the screen.";
"  ESC [H sends the cursor to the top left. Then for each row j from 1 to 16:";
"    R points a at the row; 32 is a column counter kept on the stack; the inner";
"    loop 1( ... ) steps a, fetches the cell (0 or 1), adds it to the address of";
"    the string .O (so it picks the character . or O), fetches that and prints it;";
"    1-: decrements the counter and the copy is the loop flag; ; drops the";
"    counter at the end; 13'10' ends the row. j is incremented while j is below 17.";
"  Last it prints the generation number.";
[P "/[[H"$
   1j! 1( R 32 1( a@1+:a!, ".O"+,' 1-: ); 13'10' j@1+:j! 17<)
   "Generation "$ k@#]

"G: ( -- )  compute the next generation into h, then swap the grids. A cell is";
"   alive next exactly when (neighbours OR itself) = 3: 3 neighbours, or";
"   alive with 2. No comments inside the loop: they would run every time.";
"   Inside, for each cell: a@1+a! moves to the next cell; N counts the neighbours;";
"   a@, fetches the cell itself; | ORs it in (n or c); 3= is -1 if that equals 3;";
"   1& makes it 1 or 0; a@g@-h@+ turns the address in g into the same place in h;";
"   . stores the byte. Then 1-: counts the 32 columns, and j counts the rows.";
"   At the end g@h@g!h! swaps the two grid addresses.";
[G 1j! 1( R 32 1(
      a@1+a!  N a@,| 3= 1&  a@g@-h@+.
   1-: ); j@1+:j! 17<)
   g@h@g!h!]

"Main program";

"Allocate both grids, side by side (612 bytes each, so h follows g in memory) and";
"  clear all 1224 bytes with one loop, borders included. The loop uses a as the";
"  counter and stores a zero byte at g + a.";
612_g! 612_h!
0a! 1( 0g@a@+. a@1+:a! 1224<)

"An R-pentomino near the middle and a glider near a corner (S is x y).";
17 8S 18 8S 16 9S 17 9S 17 10S
3 2S 4 3S 2 4S 3 4S 4 4S

"Clear the screen, then run until a key is pressed or 200 generations pass.";
"  Each pass: print grid g, compute the next one, add 1 to k. 1?0= is true when no";
"  key came; k@200<& joins it with the generation limit.";
"/[[2J"$ 0k!
1( P G k@1+k! 1?0= k@200<&)

"Show the cursor again: delete the next line too if the one at the start was deleted.";
"/[[?25h"$
