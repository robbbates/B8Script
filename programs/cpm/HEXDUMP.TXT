"HEXDUMP for B8Script: shows any file in hex and as text, a page of 256 bytes at a time.";
"It needs CP/M on a Z80 or an 8080, as it reads the file through the BDOS: run it with a";
"  CP/M runner, B8S HEXDUMP.B8S FILE.COM. With no name after the program's, it asks for";
"  one. On any other build it says so and ends.";
"Keys: Space or Return the next page, b the one before, q quit. Next on the last page and";
"  back on the first do nothing.";
"A page is two records, in 16 rows of 16 bytes, in MON's row format: the offset in six hex";
"  digits (the page number in four, the row's offset in two), the bytes, and the same as";
"  text with a dot for each byte below 32 or above 126. The screen is drawn in place, with";
"  a status line under the rows. Sizes up to 32,767 records (4 MB) are shown.";
"The file kit: B calls the BDOS, N puts a name in an FCB, A finds the name on the command";
"  line. Its variables: b the gateway's code, f the FCB (36 bytes), d the record buffer";
"  (two records here), t, i and c scratch.";
"Variables of HEXDUMP: s the size in records, m the pages, n the page shown (from 1), r";
"  its first record, e its bytes (128 or 256), k the key, q set to quit.";
