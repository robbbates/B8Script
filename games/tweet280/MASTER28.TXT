"MASTERMIND for B8Script, in a tweet. Break a code of four digits, each 1 to 6,";
"in ten tries. Repeats are allowed in the code and in guesses.";
"Keys: any key to start; then four digits and Return for each guess.";
"B = right digit in the right place. W = right digit in the wrong place.";
"At the end the code is shown.";

"Variables";
"  r  random state   s  the code: 4 ASCII digits in a 5-byte heap block, with a";
"     quote after them so that s@$ prints it   c  a 4-byte copy of the code";
"  a  the address of your guess (4 characters and a Return)   b  blacks";
"  w  all the matches, then (with b taken off) the whites   v  a guess digit";
"  The tries left are on the stack under the main loop, and the counters of the";
"  inner loops are on the stack too.";

"R ( -- n ): a random number 0 to 255. r = r * 75 + 74, stored back; the high";
"  byte of it (256//// then 255&) is kept, as the low bits are the least random.";
[Rr@75*74+:r!256/;255&]

"Print the title and count while waiting for a key; the count is the seed.";
"MASTERMIND: 4 digits 1-6, 10 tries. Key"$0 1(1+1?0=)r!

"The code: allocate 5 bytes for s and 4 for c. For each of 4 places, take R mod 6,";
"  add 49 (the digit 1 to 6 as a character) and store it. Then store a quote";
"  (34) after the 4 characters.";
5_s!4_c!4 1(1-:s@+R6/%;49+%.:);34s@4+.

"The game is one loop, a try a pass; the tries left (10 at first) are on the";
"  stack. Each pass:";
"  1. Print a new line and read a line of at most 4 characters: a is its address.";
"  2. Copy the code into c: two cell moves.";
"  3. Blacks: for each place, add 1 to b if the code and the guess agree.";
"  4. Whites, first as all matches in w: for each guess digit v, run over the";
"     copy c. Each byte that equals v adds 1 to w. Each byte visited is written";
"     back ANDed with 'not equal', so a match becomes 0 and can't match again;";
"     the same flag breaks the inner loop (\), after the first match.";
"  5. Print B, then w minus b with W.";
"  6. Tries left go down by 1. The loop flag is: tries left above 0, and b under 4.";
10 1("/M/J"$-4?a!
  s@@c@!s@2+@c@2+!
  0b!4 1(1-:s@+,{:}%a@+,=b@%-b!:);
  0w!4 1(1-:a@+,v!
    4 1(1-:c@+:,:v@=:w@%-w!:{0=&%.}\:);
    :
  );
  " /bB"$w@b@-#"W"$
  1-:0>b@4<&
)

"The end: drop the tries left, print a space and the code.";
